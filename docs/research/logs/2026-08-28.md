# 2026-08-28 研究日志

## M0—M3第二阶段语义病灶轮廓研究启动

- 项目负责人确认M1保留为正式实验组，最终矩阵为M0、M1、M2、M3；
- ADR-024明确该路线是独立第二阶段，不回写、不补标、不重新选择已冻结的2026预测；
- M0固定复用既有E1严格患者级OOF，避免重复消耗五个fold；
- M1固定为13类病灶的存在、对象总数、总面积比例共39项，严格患者级五折逻辑回归；它既是医生结构化征象组，也是历史标注流程偏倚上限，不能称为AI图像性能；
- M2固定使用完整有效视野RGB和13个分类别、可重叠的二值轮廓通道，不逐病灶裁图，保留非病灶信息、同图位置关系和患者多图；
- M3固定使用M2正常概率门控，并在异常条件概率上采用75% C3加25% M2，不搜索权重；
- 启动隐私安全的稀疏语义mask准备代码和同步增强/数据集实现；正式结果尚未运行或查看。

## 当前边界

- 历史标注没有逐图穷尽性协议，零通道只表示“未观察到标注”，不是确认阴性；
- S1已证明人工类别存在性与诊断高度关联，因此本轮可回答同源回顾性可行性，不能替代医生盲法、标准化新标注的独立验证；
- 2026医院回表评价继续等待外部参考诊断，与本轮并行且不可相互选模。
