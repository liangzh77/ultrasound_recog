# 研究术语表 v2

| 术语 | 本项目定义 | 不应混同为 |
|---|---|---|
| 超声有效视野ROI | JSON中的`ultrasound_rect`；从设备界面截取实际超声画面的矩形 | 病灶轮廓 |
| 人工ROI | 已由人工确认的超声有效视野矩形 | 唯一精确的医学边界真值 |
| 自动ROI | 由规则或模型从原始设备画面预测的超声有效视野矩形 | 自动病灶分割 |
| 病灶/征象分割 | JSON中`objects[].segmentation`表示的积液、滑膜、骨侵蚀等多边形 | `ultrasound_rect` |
| 患者bag | 同一患者的全部合格图像集合 | 一张图或一个目录名 |
| 图像单模态六分类 | 只使用患者多图预测正常、RA、GA、SPA、OA、损伤 | 单图疾病分类 |
| 异常条件五分类 | 已知患者异常后，在RA、GA、SPA、OA、损伤中分类 | 完整六分类 |
| 分层多模态六分类 | 图像正常/异常概率与异常五类图像+Excel条件概率组合 | 六类直接读取Excel缺失状态 |
| OOF自动ROI | ROI定位器未见过该外层患者时产生的自动ROI | 在全开发集训练后回推训练集的ROI |
| 2026时间外队列 | 225名标签暂时隐藏患者，用于冻结后一次性评价 | 调参集或路线选择集 |
| 结构化参考诊断 | 甲方为每位2026患者返回的六分类主要诊断或争议状态 | 医生笼统评价“效果不错” |
| 基础研究水平 | 有明确问题、对照、患者隔离、统计评价、失败分析和可复现报告 | 追求大量架构创新或临床部署认证 |
