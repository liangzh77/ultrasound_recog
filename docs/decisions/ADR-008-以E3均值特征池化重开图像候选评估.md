# ADR-008：以 E3 均值特征池化重开图像候选评估

## 状态

Accepted。

## 日期

2026-08-02

## 背景

E2 gated Attention MIL 的患者级分类性能明显高于 E1，但可学习注意力在 943 名多图患者中的 pooled 塌缩率为 0.6225；唯一允许的 E2-R 熵正则补救把塌缩率降到 0.3680，却使痛风和损伤 F1 相对 E2 分别下降 0.0863 和 0.0696。ADR-006 因此正确地关闭了 Attention MIL 补救路线，当前没有合格图像主模型，F0～F2 不能启动。

现有结果没有区分 E2 的收益来自“患者级端到端目标”还是“可学习注意力加权”。等权平均图像嵌入后再进行患者级分类，可以保留前者，并从结构上取消会集中到单图的注意力参数。

该结构符合 [Deep Sets](https://proceedings.neurips.cc/paper/2017/hash/f22e4747da1aa27e363d86d40ff442fe-Abstract.html) 的置换不变集合建模形式。2026 年一项多数据集医学影像 MIL 基准也报告，简单均值池化在多个中等规模任务中能够匹配或超过更复杂的 MIL 方法；该外部证据只用于事前方法合理性，不替代本项目固定五折证据。

## 决策

- 新增唯一候选 E3：同一 EfficientNet-B2、同一人工确认 ROI、384×384 等比例 letterbox、训练增强、fold、seed 和预算；唯一方法变化是从“逐图 softmax 后平均”改为“图像 embedding 等权平均后做一次患者级分类”；
- E3 不产生、解释或导出 attention 权重；所有有效图像的结构权重严格为 `1 / bag_size`，padding 为 0；
- 先运行 fold 0、5 epoch 资源 pilot；只有耗时小于1小时、峰值显存不超过9GB、外层测试未迭代且数值稳定，才允许正式五折；pilot 分数不用于选择；
- 正式五折必须一次性执行全部固定折，随后与 E1 和 E2 做患者配对 bootstrap，不得按中间折调整超参数；
- E3 只有同时通过预登记的总体性能、折方向、类别安全、校准、置换不变和资源门槛，才可成为图像主模型；
- 若 E3 失败，停止本轮均值特征池化，不自动追加 max、top-k、mean+max 或新骨干；任何新路线必须另写 ADR。

ADR-006 对 Attention MIL 和 E2-C 的停止决定继续有效；本 ADR 只以不同聚合机制窄范围重开检查点 A2。

## 被拒绝的方案

### 直接冻结 E2

拒绝。性能收益不能抵消预登记的系统性注意力塌缩和校准恶化。

### 继续调 E2-R 正则强度

拒绝。ADR-005 已明确只允许一个强度，事后继续搜索会利用同一开发集选择。

### 立即更换 ConvNeXt 骨干

拒绝。更换骨干不能直接回答患者级目标和注意力机制谁带来收益，也会同时改变表示能力与聚合机制。

### 使用 max 或 top-k 特征池化

拒绝作为当前首选。它们仍可能让单张伪影主导患者预测，且需要额外选择 k 或聚合组合。

## 后果

- 增加一个机制明确、参数更少且资源近似 E1/E2 的五折候选；
- 无 attention 不代表有病变定位能力；E3 仍只是患者级主要诊断分类器；
- A2 状态改为“E3 窄范围重开”，F0～F2继续阻塞；
- 2026 标签隐藏队列继续隔离。
