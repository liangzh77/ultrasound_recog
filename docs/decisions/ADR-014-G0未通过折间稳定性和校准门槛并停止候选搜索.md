# ADR-014：G0未通过折间稳定性和校准门槛并停止候选搜索

## 状态

Accepted。

## 日期

2026-08-03

## 背景

ADR-013允许一个且仅一个患者级正常/异常图像门控候选。G0在固定967名患者、4,543张ROI图像和固定五折上完成正式训练，总体ROC-AUC为0.8672（95% CI 0.8431～0.8898），异常灵敏度0.9061、正常特异度0.5350、macro-F1 0.7293，均达到相应预登记门槛；注意力塌缩率0.0032，资源与记录合同也通过。

但是fold 2/3 ROC-AUC仅0.6170/0.6221，只有3/5折达到0.75，低于要求的4/5；校准后ECE为0.1292，高于0.10。fold 2/3正常特异度仅0.075/0，表明失败不是总体平均或阈值展示问题，而是不同患者子集上的显著不稳定。预登记要求全部门槛同时通过。

## 决策

- G0状态定为正式门槛失败，不冻结为正常/异常图像门控模型，不用于部署或2026盲测；
- 按冻结停止规则，不运行第二骨干、第二聚合器、第二KL系数、额外seed、重分折、阈值放宽或基于五折结果的超参数搜索；
- 不删除fold 2/3，不只报告表现好的三折，也不因总体AUC、灵敏度和macro-F1通过而忽略稳定性与校准失败；
- 不把未通过门槛的G0与C3临床模型事后融合，F0～F2继续阻塞；
- G0保留为“总体有信号但内部稳定性不足”的正式阴性/部分通过证据；
- 后续只允许不改变模型选择的误差与采集异质性审计。若未来获得新的独立数据、明确的采集/切面标签或完成S1a临床标注协议，应以新的研究问题、ADR和预登记重新进入，而不是续调G0；
- 2026标签隐藏队列继续隔离。

## 被拒绝的方案

### 将折稳定门槛从4/5改为3/5

拒绝。该修改发生在结果已知后，会把预登记失败改写成通过。

### 将ECE上限从0.10放宽到0.15

拒绝。虽然校准使ECE从0.1649降至0.1292、Brier从0.1779降至0.1406，但绝对ECE门槛仍失败；不能只保留“有所改善”。

### 只用fold 0/1/4训练最终模型

拒绝。删除表现差的固定折属于结果驱动样本选择，也无法证明未来患者来自“好折”分布。

### 更换随机种子或重新分层

拒绝。当前五折在患者数和六类来源诊断上已近似平衡；fold 2/3的失败正是必须被稳定性门捕获的泛化风险。

### 立即与Excel融合

拒绝。临床信息可能掩盖图像门控的不稳定，且正常组无Excel会重新引入工作流捷径。融合不应成为绕过图像门槛的手段。

## 后果

- G0不产生可用门控模型，原分层融合路线仍缺少合格的第一层图像门；
- 总体AUC 0.8672说明ROI中存在正常/异常信息，但当前弱标签患者bag方法对患者子集/采集差异敏感；
- 下一阶段优先解释fold 2/3的采集、切面、设备、ROI几何和图像数量异质性，并等待S1a临床本体确认或新增独立数据；
- 最终研究总结必须同时呈现总体通过项、稳定性/ECE失败、fold 2/3崩溃和停止决定。
