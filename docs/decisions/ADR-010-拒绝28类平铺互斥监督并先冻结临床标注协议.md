# ADR-010：拒绝28类平铺互斥监督并先冻结临床标注协议

## 状态

Accepted。

## 日期

2026-08-02

## 背景

ADR-009要求在继续图像模型前审计已有28类多边形监督。S1覆盖967名开发患者和4,543张纳入图像，规范化合同通过，但发现：

- 28类中16类患者级五折支持充分、3类有限、9类不足；
- 4,346对跨类别多边形有正面积重叠；
- 13类的单一主要诊断占比至少0.80；
- 仅用人工标注类别存在性即可得到OOF macro-F1 0.8240和macro-AUC 0.9668；仅解剖角色也达到0.5407/0.8404；
- 未建立逐图穷尽性标注协议，因此“没有该标注”不等于真阴性；
- 546个对象没有完全位于人工确认ROI内，ROI训练转换需要显式截断规则。

## 决策

- 接受28类疾病前缀清理后的版本化数据合同，但不把“数据已规范化”等同于“监督任务已定义”；
- 拒绝把全部28类按绘制顺序覆盖成单张互斥语义mask；
- 拒绝把人工标注存在性或由全数据拟合得到的病变特征直接输入患者诊断模型；
- 暂不启动28类nnU-Net、YOLO实例分割或病变多任务正式五折；
- 先建立S1a临床标注协议：确认解剖/病变/待定本体、同义或上下位关系、逐图目标是否穷尽、可解释的负例、重叠表示、ROI边界截断和临床优先目标；
- 后续只允许对满足患者级多折支持、语义明确的窄范围目标另行预登记；重叠目标优先采用多标签通道、实例表示或分层任务头；
- 若产生病变辅助诊断特征，病变模型必须在每个外层患者fold内训练，只把严格OOF预测交给诊断模型；人工真值只用于训练/评价病变模块，不直接作为诊断输入；
- 2026标签隐藏队列继续隔离。

## 被拒绝的方案

### 立即训练28类nnU-Net

拒绝。平铺mask会覆盖医学上合理的跨类重叠，稀有类和未知阴性又会使损失函数含义不成立。

### 立即训练28类YOLO实例分割

暂缓。实例表示可以保留重叠，但不能解决9类支持不足和未标类别是否为漏标的问题。

### 直接用人工病变标签提高诊断

拒绝。人工存在性代理的高分说明它混合了真实病变、切面选择、标注流程和已知诊断，直接输入会夸大性能。

### 只选择内部最可分的病变类

拒绝。按同一开发集的疾病可分性选标签会放大选择偏差。目标选择必须先依据临床定义、支持度和可标注性，再用预登记的OOF实验评价增益。

## 后果

- S1以“审计完成、直接28类路线不通过”关闭；
- 下一阶段不是训练竞赛，而是监督协议和本体冻结；
- 现有多边形仍有价值，可用于协议确认后的病变检测、分割或解释模块；
- A2、融合和盲测保持阻塞，不因人工标签代理高分而放宽门槛；
- 所有不完整运行、阴性发现和偏差证据继续保留。
