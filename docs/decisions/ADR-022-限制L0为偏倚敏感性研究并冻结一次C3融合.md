# ADR-022：限制L0为偏倚敏感性研究并冻结一次C3融合

- 日期：2026-08-27
- 状态：Accepted
- 范围：L0人工病灶轮廓、C3临床数值基线、2026路线冻结

## 背景

L0按完整有效视野RGB加同坐标病灶二值mask第四通道完成正式五折。它没有逐病灶裁图，保留多病灶相对位置、非病灶背景和患者多图关系。L0相对E1的患者级macro-F1差为+0.0588，95%CI 0.0221至0.0955，4/5折正向。

但预登记的三个mask-only特征在不读取RGB时macro-F1达到0.3302，高于完整L0的0.2743；正常、类风湿、痛风和损伤也存在不同程度的类别安全问题。当前数据无法把L0增益归因为病灶形态或空间关系，立即要求医院逐图画病灶轮廓缺少充分依据。

## 决策

1. 当前不冻结L0为医院正式半自动诊断流程，不要求医院为2026队列补画病灶轮廓。
2. 不修改L0病灶类别、mask形态、骨干、聚合器、超参数或seed，不进行第二个L0候选。
3. 按L0预登记中已允许的范围，只运行一次L1异常条件OOF融合敏感性分析，不训练新模型。
4. L1只纳入开发队列中767名参考诊断已知为异常的患者；将L0五个异常类别概率重新归一化为条件概率，与同折C3 OOF严格按患者对齐。
5. 融合固定为`0.75 × C3 + 0.25 × L0条件概率`。权重直接复用结果早已存在的X0预登记方案，不查看L1结果搜索权重。
6. L1主要比较固定融合减C3的macro-F1配对bootstrap；同时报告五折方向和逐类F1。可信互补需要差值至少+0.01、95%CI下界大于0、至少4/5折正向且任类F1下降不超过0.05。
7. 无论L1是否通过，都不能消除mask-only偏倚结论，不能单独证明人工病灶轮廓的医学增量，也不能单独解锁2026预测。
8. 2026继续隔离；最终路线必须在开发集研究全部闭合后另行冻结，且甲方是否需要补充病灶轮廓须依据证据与工作量共同决定。

## 后果

- 研究复杂度被限制为一个确定性的CPU概率审计，而不是重新训练多模态网络；
- 若L1失败，关闭人工病灶轮廓+C3路线；
- 若L1通过，也只能记录为现有同源人工标注流程对临床模型的互补证据，仍需在偏倚和类别安全约束下决定是否值得医院投入；
- 2026不会用于选权重、选模型或补救开发集结果。
