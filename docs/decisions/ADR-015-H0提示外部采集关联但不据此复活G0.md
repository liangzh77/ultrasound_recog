# ADR-015：H0提示外部采集关联，但不据此复活G0

## 状态

Accepted

## 日期

2026-08-03

## 背景

G0患者级正常/异常门控总体AUC尚可，但fold 2/3稳定性和ECE未通过。H0按预登记检查fold代理偏移、代理对G0错误的预测和G0概率与既有代理OOF的一致性。

H0发现：六组代理均能中等预测总体错误；只有ROI外/采集导出组与ROI边缘医学控制组同时通过代理概率相关；所有代理组都不能识别fold，也没有广泛fold特征偏移。ROI外像素对G0不可见，ROI边缘可能含医学内容。

## 决策

1. H0只支持关联解释，不支持设备、操作者、切面或批次的因果归因；
2. ROI外关联不得称为G0直接捷径，因为G0没有读取ROI外像素；
3. ROI边缘控制不得称为非医学代理，因为它可能包含医学组织；
4. 不按这些代理删除、重加权患者，不重分折、不调阈值、不训练第二个G0；
5. ADR-014继续有效，G0和F0～F2保持停止；
6. 若重开图像路线，前置条件是新的可审计采集元数据或独立标注队列，并需单独预登记。

## 备选方案

### 用代理重加权或剔除患者后重训G0

拒绝。H0是事后解释性审计，代理可能含医学内容或只代表共同流程；据此调数据会形成结果驱动选择。

### 把ROI外关联称为模型捷径

拒绝。G0输入边界不包含ROI外像素；最多说明共同采集/导出过程关联。

### 因fold整体不可识别而认定没有异质性

拒绝。阴性H0-A只说明已测代理没有广泛整体偏移，不能排除未测设备、操作者、切面、病情构成或高阶交互。

## 后果

- G0仍不是可冻结模型；
- H0不会产生诊断权重、部署阈值或2026预测；
- 后续图像研究应优先改善元数据与外部验证设计，而不是继续同数据候选搜索；
- S1a临床确认仍是当前独立阻塞项，不由H0替代。
