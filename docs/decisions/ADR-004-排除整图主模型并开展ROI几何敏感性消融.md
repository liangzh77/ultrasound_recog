# ADR-004：排除整图主模型并开展 ROI 几何敏感性消融

## 状态

Proposed；E1-S 完成后转为 Accepted 并冻结后续 MIL 输入。

## 日期

2026-08-02

## 背景

E0整图和E1 ROI患者级五折均已完成。E1总体 macro-F1 略高，但SPA和损伤灵敏度下降。随后进行的患者级非医学代理审计发现，E0可见的边框和ROI外背景仅凭简单统计即可达到 macro-F1 0.3983，明显高于E0 CNN的0.2014。ROI输入仍有长宽比和分辨率代理风险，但不再暴露最强的整图外部背景。

## 决策

- E0不再作为最终图像主模型候选，只保留为捷径风险对照；
- 后续主线只读取人工确认ROI，不增加上下文边距；
- 在进入Attention MIL前运行一次E1-S敏感性消融；
- E1-S把完整ROI直接缩放到固定正方形，除缩放方式外与E1完全相同；
- 不把ROI坐标、原始尺寸、文件属性或患者图像数作为显式输入；
- E1-S门槛按研究审计文档预先固定，不搜索多个比例或裁剪策略。

## 备选方案

### 继续使用整图

拒绝。外部背景代理性能远高于整图CNN，无法把内部五折结果解释为医学内容识别。

### 给ROI增加上下文边距

拒绝。它会重新引入已经证实与诊断强相关的机器界面和外部背景。

### 直接固定原letterbox ROI

暂缓。它保存解剖几何，但padding量显式暴露ROI长宽比；先用一次固定拉伸敏感性分析判断结论对该代理的依赖程度。

### 搜索多种裁剪、拉伸和padding策略

拒绝。反复在同一五折上搜索会增加选择偏差，也可能为了内部高分重新选择捷径。

## 后果

- ROI外信息被排除，降低明显的设备/导出模板捷径；
- E1-S可能因非等比拉伸损伤解剖比例，结果只能作为敏感性证据；
- 如果固定拉伸不能达到预设安全门槛，原letterbox仍可用于研究，但必须把采集代理风险列为主要限制；
- 2026标签隐藏队列仍保持隔离，不能用于决定输入方式。
