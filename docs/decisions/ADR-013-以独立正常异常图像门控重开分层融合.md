# ADR-013：以独立正常/异常图像门控重开分层融合

## 状态

Accepted。项目负责人于2026-08-03明确确认G0唯一候选和九项门槛；允许按冻结配置实现和验证，正式训练仍须通过代码、dry-run和资源pilot门。

## 日期

2026-08-03

## 背景

ADR-006 和 ADR-009 关闭了 E2/E2-R/E3 六分类图像聚合器路线：现有候选没有同时通过总体、类别安全、注意力和校准门槛，F0～F2 因而阻塞。S1a 病变语义复核又必须等待临床书面确认，不能提前训练病变辅助模型。

但 ADR-001 的原始分层设计并不要求一个图像模型同时完成全部六类：正常组没有 Excel，因此正常/异常概率必须只来自图像；只有异常条件下的 RA、GA、SPA、OA、损伤五分类才进入图像/临床融合。此前 E0～E3 直接优化六类主要诊断，尚未正式验证这一独立二分类门控。

六分类失败不能直接证明正常/异常门控失败。反过来，事后把一个失败六分类模型宣布为门控模型也缺少预登记。需要以新的研究问题、标签合同和门槛独立评估。

## 提议决策

- 新增 G0：患者级正常/异常图像门控；不读取任何 Excel 或其存在性；
- 使用现有固定患者五折、人工确认 ROI 和同一 EfficientNet-B2 资源合同；
- 唯一候选使用 gated Attention MIL 加固定 0.05 归一化注意力 KL，从 ImageNet 权重重新训练二分类头；
- G0 的标签、门槛、阈值选择、校准、停止规则和产物合同以[冻结预登记](../project/G0患者级正常异常图像门控实验预登记_2026-08-03.md)和配置`configs/research/g0_roi_normal_abnormal_gate_b2.yaml`为准；配置SHA-256为`4a06e647e6b1ba5e4223a4ec752110bf71b9bfc257e8b134271c508c9c53ed72`；
- G0 不推翻 E1/E2/E2-R/E3 的六分类结论，也不恢复骨干或聚合器搜索；
- G0 全部通过只允许另行预登记 F0～F2，不直接冻结六分类诊断系统或运行 2026 盲测；
- G0 任一正式门槛失败则停止此路线，继续等待 S1a/S1b 或新增开发数据。

## 被拒绝的方案

### 直接复活 E2-R 作为六分类主模型

拒绝。它已违反预登记的痛风和损伤类别安全门，不能因融合被阻塞而事后改判。

### 把既有 E2-R 的正常概率直接宣布为正式门控

拒绝。该模型按六分类目标训练，门控问题、阈值和校准并未预登记。它只能作为 G0 的参考对照。

### 同时比较多个二分类骨干或聚合器

拒绝。当前开发集已参与多轮模型研究；无约束搜索会继续扩大选择偏差。G0 只允许一个与既有工程和资源证据最接近的候选。

### 直接用 C3 生成六类结果

拒绝。C3 只覆盖 767 名异常患者，正常组系统性没有临床数据；用“无表格”推断正常会形成工作流标签捷径。

### 等临床 S1a 完成后再做任何工作

拒绝作为唯一安排。S1a 仍是病变辅助训练的硬门，但 G0 不消费病变标签，可以并行推进原始分层诊断架构。

## 预期后果

- 若 G0 通过，项目首次获得与 ADR-001 对齐的图像正常/异常门控候选，并可严格预登记异常五分类 F0～F2；
- 若 G0 失败，得到的是新的阴性证据，不会通过搜索第二模型掩盖；
- 原六分类图像模型、S1a 临床门、2026 标签隔离和单模型资源限制均保持不变；
- 最终报告要区分“六分类图像模型失败”和“二分类门控是否通过”，不得混写。

## 证据与依据

- [ADR-001](ADR-001-采用患者级六类主要诊断与分层多模态融合.md)：正常/异常只用图像、异常五分类再融合；
- [ADR-006](ADR-006-E2R未通过类别安全门槛并关闭A2.md)：允许获得新的独立方法决策后再考虑融合；
- [ADR-009](ADR-009-E3未通过总体及类别安全门槛并转向标注监督审计.md)：禁止继续无约束聚合器搜索；
- [E2-R 五折结果](../project/E2R_注意力熵正则补救五折结果_2026-08-02.md)：固定熵正则已降低注意力塌缩，但六分类类别安全失败；
- [Attention-based Deep Multiple Instance Learning](https://proceedings.mlr.press/v80/ilse18a.html)：患者 bag 的置换不变注意力聚合依据；
- [TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378) 与 [PROBAST+AI](https://www.bmj.com/content/388/bmj-2024-082505)：透明报告和偏倚审查框架。
