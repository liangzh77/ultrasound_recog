# ADR-005：E2 性能门槛通过但注意力塌缩后启动单次熵正则补救

## 状态

Accepted。

## 日期

2026-08-02

## 背景

E2 gated Attention MIL 完成固定五折。其 OOF macro-F1 为 0.3663，比 E1 高 0.1508（配对 95% CI +0.1125～+0.1890），五折方向均为正；但 943 名多图患者中有 62.25% 的最大注意力不低于 0.95，超过预设上限 50%，并且 4/5 折失败。E2 的 ECE 和 Brier 也明显差于 E1。

预注册规则明确要求 E2 成为图像主模型时注意力不得存在系统性塌缩。不能因为分类分数较高而事后删除该门槛、提高阈值或排除不利患者。

## 决策

- E2 暂不冻结为图像主模型，检查点 A2 保持开放；
- 暂停 E2-C ConvNeXt 骨干挑战，因为只换骨干不能直接处理聚合权重塌缩，并会扩大开发集上的模型搜索；
- 只允许一次机制明确的补救 E2-R：对多图患者的注意力分布增加归一化 `KL(attention || uniform)` 正则；
- 正则系数预先固定为 `0.05`，单图患者正则为 0；不得根据任何外层 fold 结果搜索或修改该系数；
- E2-R 除这一项外复用 E2 的人工确认 ROI、384×384 letterbox、EfficientNet-B2、增强、优化器、五折、seed、epoch、早停和资源限制；
- 先做 fold 0 的 5 epoch 资源/合同试运行；通过后完成固定五折；pilot 分数不用于选择。

## E2-R 预设门槛

E2-R 进入图像主模型候选必须同时满足：

1. pooled 多图注意力塌缩率不超过 0.50；
2. OOF macro-F1 不低于 0.3463（E2 点估计减 0.02），且至少比 E1 高 0.01；
3. 至少 3/5 折 macro-F1 高于 E1 同折；
4. 任一类别 F1 相对 E2 不下降超过 0.05；
5. ECE 不高于 E2 的 0.4519，multiclass Brier 不高于 E2 的 1.0291；
6. bag 顺序不变、外层测试隔离、资源和产物审计全部通过。

如果 E2-R 失败，不运行第二个正则强度，不把 E2 的注意力解释为病变定位，并停止本轮 Attention MIL 补救路线。届时 A2 必须明确选择保守主分析、敏感性模型，或判定当前图像模型尚未达到预设研究标准，不能用时间外标签反向选择。

## 备选方案

### 直接选择 E2

拒绝。虽然性能提升明确，但违反预设注意力门槛，并存在明显过度自信。

### 修改塌缩阈值或只保留通过的 fold

拒绝。这是结果已知后的规则修改，会造成选择偏差。

### 立即运行 ConvNeXt

暂缓。骨干变化可能改变分数，但不直接约束注意力分布，也会同时增加算力和模型选择空间。

### 多个正则强度网格搜索

拒绝。当前只有 967 名开发患者，在相同 OOF 上搜索多个强度会低估选择偏差。

## 后果

- 增加一次完整五折训练，按 E2 实测预计总 GPU 时间约 3 小时，满足单 run 12 小时限制；
- 若轻度正则能降低塌缩而保留性能，可获得更符合预设标准的患者聚合模型；
- 若失败，仍能以预先固定的一次实验回答“性能收益是否依赖极端单图选择”；
- E2 的阳性分类结果、校准恶化、失败注意力门槛和资源误停全部保留在最终报告。
