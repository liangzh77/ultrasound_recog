# ADR-025：M3未超过自动分层对照并停止历史语义轮廓调优

- 日期：2026-08-28
- 状态：Accepted
- 范围：M0—M3历史语义病灶轮廓第二阶段研究

## 背景

ADR-024预登记的四组研究已完成。M1人工结构化征象macro-F1为0.6351，但包含诊断相关的类别标注和历史工作流偏倚；M2完整RGB加13类语义mask为0.3327，虽比M0高0.1172，却比M1低0.3024，且五折均低于M1。M3按固定75% C3加25% M2异常条件概率融合后为0.5676，比M2高0.2348，但比M0正常门控加C3异常分类对照低0.0342（95% CI −0.0578～−0.0096），仅2/5折正向。

## 决策

1. M3记为未超过更简单自动分层对照，不纳入当前交付或2026冻结路线。
2. M2记为“相对纯图像有增益、未超过人工结构化征象”，不得宣称形状、纹理和空间关系具有独立诊断增量。
3. M1保留为医生结构化征象内部可行性和历史标注流程偏倚上限，不称为AI图像识别性能，也不直接转为临床交付模型。
4. 停止在现有967名历史开发患者上追加语义通道骨干、类别筛选、损失函数、seed、后处理或融合权重搜索。
5. 若医院希望继续半自动路线，下一步必须是统一协议下的新标注和独立验证；标注者尽量不知道最终诊断和AI预测，并逐图区分不存在、不可见和不确定。
6. ADR-023冻结的R0＋E1＋C3 2026预测、医院回表和一次性评价合同完全不变。

## 理由

现有结果已经回答了低复杂度研究问题：类别化轮廓能帮助图像模型，但像素轮廓模型远未复现结构化病灶类别的可分性；临床Excel是M3提升的主要来源，而混入M2没有超过更简单对照。在同一诊断相关标注数据上继续搜索会放大选择偏差，无法解决最关键的标注完整性和独立验证问题。

## 后果

- M0—M3历史回顾性阶段完成并保留全部阳性与阴性结果；
- 当前工程不再启动新的本机语义轮廓训练；
- 研究工作转回等待医院2026参考诊断，或等待医院决定是否开展标准化新轮廓标注；
- 新标注若启动，应另行预登记样本、标注协议、盲法、主要指标和停止门槛，不能回填本轮OOF。
