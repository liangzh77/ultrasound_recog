# ADR-001：采用患者级六类主要诊断与分层多模态融合

## 状态

Proposed

## 日期

2026-07-24

## 背景

本项目原有训练把每张超声图像独立分类为七种疾病，虽然数据拆分按患者进行，但模型没有把同一患者的多张图合并判断。新数据同步并完成 ROI 人工确认后，客户明确了以下事实：

- 正常组没有 Excel 化验数据；
- RA、GA、SPA、损伤患者可能合并 OA，现有目录只表示主要诊断；
- `膝关节2026未标注` 的真值由客户保存，当前不提供；
- 滑膜囊肿样本少、合并情况复杂，不参加本轮研究；
- 最终诊断必须汇总同一患者的全部图像。

现有数据在排除滑膜囊肿后共有 967 名患者、4,543 个有效配对图像，目标类别为正常、RA、GA、SPA、OA、损伤。

## 决策

1. 主要终点定义为**患者级六分类主要诊断**，使用 Attention-based MIL 聚合同一患者的全部合格 ROI 图像。
2. 保留一个独立的**疾病无关多标签病变/影像表现任务**，用于表达伴随 OA 表现和提供可解释性；像素标签统一去除 `N/RA/OA/GA/SPA-/损伤-/滑膜囊肿-` 等疾病前缀，不把主要诊断 softmax 解释为全部合并症。
3. 滑膜囊肿患者不进入本轮主要诊断 manifest 和五折划分，但不删除原始数据。囊肿可继续作为影像表现标签。
4. 正常/异常判断只使用图像；异常患者的 RA、GA、SPA、OA、损伤五分类使用图像 + Excel。最终通过条件概率组合为六分类结果。
5. `膝关节2026未标注` 作为冻结后的盲测队列，不参与开发和调参。
6. 切面、病变和主要诊断模块独立评估，用软特征或晚期融合连接；不采用硬级联作为主路线。
7. 原图不裁掉或覆盖；训练时根据 `ultrasound_rect` 在内存中动态读取 ROI。

## 备选方案

### 继续做逐图七分类

- 优点：沿用旧脚本最简单。
- 缺点：滑膜囊肿不再是研究目标；同一患者多图没有联合；多图患者会被过度加权。
- 结论：拒绝。

### 直接做患者级六分类图像 + Excel 融合

- 优点：模型结构表面上最统一。
- 缺点：正常组系统性没有 Excel，模型可以仅凭“是否缺表格”识别正常；在 2026 队列中会产生明显分布偏移。
- 结论：拒绝，改用分层条件概率融合。

### 将疾病目录作为多标签疾病真值

- 优点：可以输出多种疾病同时存在。
- 缺点：当前只有主要诊断目录，没有完整次要诊断真值；把未记录的合并症当阴性会制造错误标签。
- 结论：拒绝。疾病仍做主要诊断六分类，合并表现由病变多标签表达。

### 切面 → 病变 → 诊断硬串联

- 优点：流程接近人工阅读顺序。
- 缺点：切面或病变模型一旦错误，后续没有恢复通路；当前还没有切面真值。
- 结论：拒绝硬串联，保留直接图像通路并采用软融合。

### 物理删除滑膜囊肿原始数据

- 优点：训练目录表面更简洁。
- 缺点：不可逆，失去以后研究或作为伴随表现分析的可能。
- 结论：拒绝。只在研究清单中排除。

## 后果

### 正面影响

- 评价单位与临床诊断单位一致；
- 避免正常组缺 Excel 造成的标签捷径；
- 能在不伪造合并症真值的前提下表达伴随 OA 影像表现；
- 2026 队列可形成可信的时间外盲测；
- ROI、MIL、切面和病变模块的贡献可以通过消融实验分别验证。

### 成本和限制

- 必须先建立真实患者身份键和固定五折；
- 需要重写患者 bag 数据加载和患者级评价；
- 切面模块必须等待新标注；
- 病变多标签训练前需要确认标注是否穷尽；
- 正常组没有临床数据时，无法验证一个真正的直接六分类多模态模型；
- 本轮结果只能称为主要诊断研究，不能宣称识别所有合并疾病。
