# ADR-009：E3 未通过总体及类别安全门槛并转向标注监督审计

## 状态

Accepted。

## 日期

2026-08-02

## 背景

ADR-008 允许 E3 作为唯一无 attention 的患者级聚合候选。E3 完成固定五折后，macro-F1 为 0.3010，明显优于 E1，且4/5折方向为正、校准良好。这说明患者级端到端目标本身确有价值。

但 E3 低于预设最低 0.3463；相对 E2，正常、痛风和损伤 F1 分别下降 0.0591、0.1710 和 0.2267，违反最大下降0.05的类别安全门槛。因此消除注意力塌缩并没有得到足够安全的分类性能。

## 决策

- E3 不晋级，不冻结为图像主模型；
- 不运行 max、top-k、mean+max、额外 dropout/学习率或新骨干搜索；
- ADR-006 对 E2/E2-R/E2-C 的停止决定继续有效，ADR-008 的单次 E3 路线至此关闭；
- 检查点A2仍为“无合格图像主模型”，F0～F2不得启动；
- 下一步转为数据和监督信号问题：先只读审计现有规范化区域/病变标注，确认28类词典、图像/患者覆盖、类别支持、共现、来源/疾病捷径和五折分布；
- 只有审计显示存在足够、疾病名无关且可做患者级隔离的病变监督，才另写ADR预登记分割、检测或多任务辅助路线；
- 2026隐藏参考标准继续不使用。

## 被拒绝的方案

### 因 E3 相对 E1 显著提高而降低门槛

拒绝。预登记要求全部门槛同时通过，不能在结果出现后删除总体性能或类别安全条件。

### 对 E2 和 E3 做事后概率集成

拒绝。当前没有预登记集成规则，且会在同一开发集上增加权重选择；两个不合格模型的集成不能自动成为合格模型。

### 立即启动图像与 Excel 融合

拒绝。临床 C3 的高分不能掩盖图像模型不合格，也不能让正常组的 Excel 缺失成为标签捷径。

### 继续搜索 bag 聚合器

拒绝。E2/E2-R/E3 已分别覆盖可学习attention、正则attention和等权feature pooling；继续无约束搜索会扩大开发集选择偏差。

## 后果

- 图像主线保留完整阳性和阴性证据，但暂不产生部署候选；
- 研究转向利用客户已经投入成本标注的区域/病变信息，而不是重复调整弱标签聚合器；
- 下一检查点首先是标注监督可用性审计，不是直接训练新模型；
- 融合和盲测继续等待真正冻结的图像模型。
