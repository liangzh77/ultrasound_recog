# ADR-016：以异常五分类OOF互补性门重开受控融合探索

## 状态

Accepted

## 日期

2026-08-03

## 背景

现有967名患者已经完成六类图像模型、正常/异常门控和异常五分类临床基线。E2图像六分类macro-F1为0.3663；G0总体AUC为0.8672，但fold 2/3和ECE未通过；C3在767名异常患者上的临床数值五分类macro-F1为0.7185。正常组没有同标准化验数据，直接六类图像+Excel融合会把“是否存在化验表”变成正常/异常捷径。

ADR-014和ADR-015因此停止把失败G0与C3包装为完整六分类融合。项目负责人现明确要求：在无法新增数据的条件下继续研究现有数据，并优先检验异常患者内部ROI图像与Excel数值的互补性。

## 决策

1. 新路线只回答767名已知异常患者的RA、GA、SPA、OA和损伤五分类，不重新解释G0，也不声称形成完整六分类模型；
2. 第一阶段X0不训练模型，只连接既有严格OOF：把E2五个异常类别概率重新归一化，与C3按预先固定的0.25/0.75权重进行算术概率融合；不得搜索权重；
3. X0同时量化C3错误被E2正确挽救的比例、涉及fold和类别，以预登记“固定融合门或错误挽救门”决定是否值得投入D0专用异常五分类图像训练；
4. 只有D0通过独立预登记的性能、类别安全、校准、注意力和资源门，才允许训练F0无随机遮蔽与F1随机遮蔽15%化验值两个融合候选；
5. 融合只使用人工确认ROI和C3八个允许数值；诊断、病程、日期、身份、文件名、原始路径和显式缺失指示器不得进入模型；插补、缩放和随机遮蔽均限定在outer train；
6. 固定原患者五折，所有模型按患者级OOF评价；不重分折、不删除不利fold、不在同一OOF上搜索骨干、融合权重或遮蔽率；
7. X0、D0、F0和F1均为探索性开发证据。它们不能复活G0、不能解锁2026预测，也不能替代独立时间外验证；
8. 单折先过5 epoch资源pilot；GPU单折目标小于10小时、最好小于12小时且绝不超过24小时，CPU最多2线程，峰值显存门为9GB。

本ADR只在“异常患者条件五分类探索”范围内取代ADR-014/015关于当前数据不得开展融合的条款；二者关于G0失败、完整六分类、2026隔离和不得作部署声明的决定继续有效。

## X0晋级门

满足以下任一组才允许预登记D0：

### 固定融合门

- 0.75 C3 + 0.25 E2条件概率相对C3的macro-F1至少提高0.01；
- 患者级配对bootstrap 95% CI下界大于0；
- 至少4/5折方向为正；
- 任一类别F1下降不超过0.05。

### 错误挽救门

- E2条件top-1正确挽救至少15%的C3 top-1错误；
- 挽救分布于至少4个fold；
- 挽救涉及至少3个疾病类别。

固定融合门用于判断现有输出能否直接互补；错误挽救门只用于判断专用D0是否值得训练，不表示现有E2可晋级。

## 被拒绝的方案

### 直接做正常加五病种的六类融合

拒绝。正常组无同标准临床表，模型可利用表是否存在完成正常/异常判断。

### 看到X0结果后搜索融合权重

拒绝。X0使用同一开发队列，结果驱动权重搜索会把描述性检查变成新的顺序过拟合。

### 直接把C4高分作为融合依据

拒绝。C4显式使用缺失指示器，其高分已被认定为工作流偏差上限。

### 把X0成功称为联合训练成功

拒绝。X0只是现有OOF的固定概率组合，不产生新权重；真正联合训练须等待D0门并独立预登记F0/F1。

## 后果

- 可以在不新增数据、不越过正常组化验缺失边界的前提下，低成本判断图像是否提供临床互补信息；
- 若X0两组门均失败，D0和融合保持停止并记录阴性结果；
- 若X0通过，只说明值得训练D0，不保证最终融合会超过C3；
- 后续报告必须同时保留C3强基线、图像弱基线、固定融合结果和正常/异常门控未解决的限制。
