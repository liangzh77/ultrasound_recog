# ADR-002：固定临床特征白名单与标注规范化前置条件

## 状态

Accepted

## 日期

2026-07-24

## 背景

本轮异常五分类的 Excel 数据包含年龄、性别、诊断、病程、检查日期和六项化验。审计发现：

- 767/767 名纳入研究的异常患者都填写了“诊断”，直接暴露主要诊断；
- 患者编号也以 GA、OA、RA、SPA、损伤等类别信息命名；
- 病程原始文本中混有银屑病、外伤、骨折等诊断或病因线索；
- 超声检查日期暴露数据采集批次；
- 不同疾病的化验缺失模式明显不同，仅根据六项化验是否存在组成的缺失模式，在当前数据上就具有很强的类别识别能力；
- 正常组没有 Excel，不能让六分类模型读取 Excel 是否存在；
- 当前 88 → 28 类像素区域规范化仍停留在 dry-run，实际训练类别缓存尚未更新。

## 实施状态更新（2026-08-02）

背景中“88→28仍停留在dry-run”是2026-07-24作出本ADR时的历史状态，现已由版本化非dry-run产物取代。当前标注版本为`annotations_62ecb01c4d77`，类别恰为28，疾病前缀残留为0；S1已完成覆盖、支持度、重叠和标注捷径审计。规范化前置条件已经落实，但[ADR-010](ADR-010-拒绝28类平铺互斥监督并先冻结临床标注协议.md)表明28类仍不能不经临床协议直接转换成互斥分割任务。

## 决策

### 1. 固定临床特征白名单

异常五分类图像 + 临床融合模型只允许使用：

```text
sex
age_years
esr_mm_h
crp_mg_l
anti_ccp_u_ml
rf_iu_ml
hla_b27
uric_acid
```

主结果不使用病程。客户以后确认病程表示“诊断前的症状持续时间”时，可以把纯时长转换成 `symptom_duration_days`，作为预设的次要消融实验。

以下字段禁止进入模型输入：

```text
诊断
编号、姓名、person_key
患者目录名、文件名、完整路径
病程原始文本
超声检查日期或诊断日期
Excel 是否存在
数据来源批次
带疾病前缀的像素区域类别
```

身份字段可用于连接和患者级分折，诊断可用于生成真值，日期可用于质控或时间外验证，但它们与模型特征严格隔离。

### 2. 保持正常组分层融合

- 正常/异常判断只读取患者级图像；
- Excel 只参与异常患者内部的 RA、GA、SPA、OA、损伤五分类；
- 最终通过条件概率组合为六分类；
- 不允许用 Excel 是否存在判断正常。

### 3. 将 28 类标注重建设为训练前置条件

本次只记录任务，不立即重建。

在训练任何分割、病变识别或基于病变特征的诊断模型前，必须：

1. 非 dry-run 运行 `tools/01_clean_labels.py`；
2. 在本轮版本化派生目录中重新生成完整标注；旧 `workspace/data/shared_derived/cleaned/` 作为历史产物保留，不直接覆盖；
3. 确认 `category_mapping.json` 恰为 28 个疾病无关类别；
4. 确认类别名不含 N、RA、OA、GA、SPA、损伤、滑膜囊肿等来源前缀；
5. 核对有效图像/JSON 覆盖数与患者 manifest；
6. 在数据加载器中增加前缀泄漏测试，检查不通过时拒绝训练。

## 建议实验：训练时随机遮蔽化验项

随机化验项遮蔽已经登记为推荐的稳健性实验，但具体概率尚未由项目负责人确认为最终固定参数。

随机化验项遮蔽只作用于训练过程，不修改原始 Excel：

1. 先根据当前训练折计算各化验项的插补值和标准化参数；
2. 每次读取一个训练患者时，对每个原本有值的化验项目独立采样；
3. 建议从 `p=0.15` 开始，即每个已有化验值有 15% 概率在本次迭代中临时不可见；
4. 被遮蔽的连续值替换为训练折的中性插补值，标准化后通常为 0；
5. HLA-B27 被遮蔽时使用中性/未知编码；
6. 年龄和性别不参与该遮蔽；
7. 验证、测试和真实推理时关闭随机遮蔽，只处理真实缺失值；
8. 同时保留 `p=0` 的无随机遮蔽对照，判断该策略是否改善隐藏队列的稳健性；
9. 遮蔽概率对所有疾病相同，不使用诊断类别决定遮蔽规则，也不根据测试集调参。

该过程等价于临床表格的 feature dropout。它让同一患者在不同训练轮次呈现不同的化验子集，迫使模型同时利用图像和真正的化验数值，降低对固定“检查套餐”的依赖。

主结果不把真实缺失指示器作为显式特征；另设“仅缺失模式”和“加入缺失指示器”敏感性实验，用于量化临床工作流偏差。

## 备选方案

### 直接使用 Excel 全部列

- 优点：实现简单。
- 缺点：诊断、编号、病程文本和日期会直接或间接暴露答案。
- 结论：拒绝。

### 不做化验项遮蔽

- 优点：训练数据保持原样。
- 缺点：模型容易依赖疾病特异的检查完整性，在不同医院或真实队列中失效。
- 结论：保留为 `p=0` 对照，不作为唯一主实验。

### 把缺失指示器直接作为主特征

- 优点：通常能提高内部数据拟合。
- 缺点：当前缺失模式主要反映医生开检验的流程，可能夸大诊断能力。
- 结论：只作为敏感性实验。

### 立即把原始病程文本送入文本模型

- 优点：可以利用更多病史信息。
- 缺点：文本含疾病名、病因和医生已知诊断后的总结，标签泄漏不可控。
- 结论：拒绝；只保留以后经定义确认的纯数值症状时长。

## 后果

### 正面影响

- 训练输入有稳定、可测试的字段边界；
- 降低诊断、身份、时间批次和检查流程造成的虚高指标；
- 同一模型可以处理不同化验完整度的异常患者；
- 图像、临床数值和缺失模式的贡献可以通过消融实验分别测量；
- 28 类标注重建成为显式前置条件，不会被以后训练步骤遗漏。

### 成本和限制

- 需要实现折内插补、标准化和 feature dropout；
- 随机遮蔽可能降低内部验证分数，但有望提高真实队列稳健性；
- 正常组没有同标准临床数据时，仍不能训练真正的直接六分类多模态模型；
- 病程暂时不能用于主结果。
