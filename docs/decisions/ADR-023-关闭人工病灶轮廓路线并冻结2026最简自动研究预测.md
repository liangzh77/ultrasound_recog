# ADR-023：关闭人工病灶轮廓路线并冻结2026最简自动研究预测

- 日期：2026-08-27
- 状态：Accepted
- 范围：开发集路线闭合、2026一次性预测、医院工作量

## 证据

1. R1证明R0自动有效视野替代人工有效视野对E1六分类无有意义损害，4,543张图全部检出，病例审阅无系统性内容裁剪；因此医院无需提供有效视野矩形。
2. E1/R1绝对六分类macro-F1约0.22，不能称为可独立临床诊断的全自动系统。
3. L0完整RGB加人工病灶mask相对E1总体提高0.0588，但正常与若干类别安全不足；仅三个mask存在/面积特征macro-F1为0.3302并超过L0，强烈限制医学归因。
4. L1固定75% C3加25% L0异常条件概率相对C3下降0.0107，95%CI跨0，仅2/5折正向并恶化校准。

## 决策

1. 关闭人工病灶轮廓作为当前正式输入的路线，不要求医院为2026队列补画病灶多边形。
2. 不再训练或搜索L0候选，不搜索L0+C3权重；保留全部阳性、阴性和偏倚结果进入最终研究报告。
3. 2026采用此前在标签隐藏状态下预登记的最简自动研究预测：R0五折检测器的框坐标中位数提供有效视野；E1五折患者概率等权集成输出图像六分类；冻结C3五折异常条件概率按既定分层公式组合。
4. 分层公式保持不变：`P(正常)=P_E1(正常)`，`P(异常疾病d)=(1-P_E1(正常))×P_C3(d|异常)`。
5. 同时向医院提供图像单模态和分层多模态两个冻结结果、Top-1/Top-2、六类概率、ROI状态和低置信度提示；不依据2026结果选择其中一个作为“最佳模型”。
6. 2026输出是研究评价材料，不是临床独立诊断。甲方返回结构化六分类参考诊断后，按冻结评价程序一次性统计；不得回头更换ROI、模型、权重或阈值。

## 理由

该路线不增加医生画框或画轮廓的工作量，复用已经冻结的R0/E1/C3产物，研究复杂度最低，也能诚实回答“现有图像模型单独表现如何、加入常规临床数值后时间外表现如何”。它不掩盖开发集图像性能不足，也不把C3强表现错误归功于超声图像。
