# ADR-024：以四组语义病灶轮廓研究重开独立半自动路线

- 日期：2026-08-28
- 状态：Accepted
- 范围：历史人工病灶轮廓、患者多图六分类、临床数值融合、第二阶段研究

## 背景

L0只把13类病灶轮廓合并成一张二值掩膜，模型知道“哪里被圈出”，但不知道轮廓类别。它不能回答标准化医生标注中的类别、数量和分类别形状是否具有诊断增量。S1人工类别存在性审计虽达到macro-F1 0.6087（仅病变角色），却混合了真实医学征象、切面选择、非穷尽标注及标注者可能已知诊断造成的流程偏差，不能称为AI图像识别性能。

项目负责人确认重新开展四组实验，并要求保留完整有效视野、同图多病灶相对位置、病灶外信息和患者多图综合判断；不采用逐病灶裁图。

## 决策

1. 新研究是独立第二阶段，不修改ADR-023冻结的2026预测、医院回表或一次性评价合同。
2. 在相同967名开发患者、固定患者级五折上运行四组：
   - M0：完整有效视野ROI RGB患者多图基线，直接复用输入和方法完全相同的E1严格OOF；
   - M1：13类病灶各自的患者级存在性、对象总数和总面积比例，共39项人工结构化征象，固定折内标准化加类别平衡Logistic Regression；
   - M2：完整有效视野RGB加13个独立、允许重叠的语义轮廓通道，患者内多图等权概率平均；
   - M3：M2与冻结C3临床数值OOF的固定分层融合，不搜索权重。
3. M1的面积定义为同类掩膜在患者全部输入ROI画布上的阳性像素总数除以`图像数×384×384`；同类重叠区域只计一次，对象数保留多边形个数。
4. M2不把所有类别压成互斥mask。每类一个二值通道，允许滑膜血流等征象与其他区域重叠；RGB、所有mask使用完全相同的几何变换。
5. M2不裁出单个病灶。每张图仍保留完整有效视野RGB、病灶外组织、多个病灶的相对位置；同一患者多张图共同形成患者级判断。
6. M3固定使用M2的正常概率作为正常/异常门控；异常条件分布固定为`0.75×C3 + 0.25×M2异常条件概率`，禁止按结果搜索权重。
7. 四组均只使用开发队列，禁止读取或补标2026队列，直至其既定外部评价闭合。
8. 本轮属于历史标注回顾性可行性研究。未出现某类轮廓只表示“历史标注未观察到”，不等于医学阴性；M1或M2高分不得直接解释为纯图像识别能力。
9. 若回顾性结果显示路线有价值，才向医院提出标准化新标注：逐图记录存在、不存在、不可见、不确定，并尽量使标注者不知道最终诊断和AI预测。新标注结果必须作为独立验证，不能回填本轮开发OOF。

## 理由

四组能以有限复杂度拆分三个问题：医生结构化征象本身有多强，完整图像与轮廓形状/空间关系是否在此基础上增加信息，以及常规Excel能否再增加信息。M1保留为正式组，可以防止把M2的高分误归因于像素和形态；M0与M3分别提供图像基线和临床实用流程边界。

## 后果

- ADR-023对当前2026交付仍然有效；其“关闭人工轮廓”只适用于当时的无语义L0路线和当前交付，不再被解释为否定第二阶段标准化语义轮廓研究。
- 历史数据可以立即完成M0、M1、M2、M3回顾性比较，但最终是否建议医院使用半自动流程仍需结合偏倚、类别安全、标注工作量及后续标准化验证。
- M1是必要的正式对照，同时也是标注流程偏倚上限；报告必须同时给出这两种解释。
