# ADR-020：以完整有效视野RGB加人工病灶掩膜研究辅助诊断

- 状态：Accepted
- 日期：2026-08-27
- 范围：人工病灶轮廓、患者多图六分类、半自动诊断候选

## 背景

项目负责人增加了一个研究问题：若全自动识别结果不足，医生人工画取病灶轮廓后，AI是否能得到更好的患者级六分类结果。

最初考虑过把每个多边形变为带边距的最小外接矩形，并将多个病灶小图共同送入分类器。该做法会丢失病灶之间的相对位置和病灶外组织信息，也会把同一原图拆成不自然的独立实例，不符合本项目需要综合完整图像和患者多图判断疾病的目标。

## 决策

1. 不使用逐病灶小图或逐病灶外接矩形作为L0输入。
2. 每张原图保留完整人工确认超声有效视野RGB；所有纳入病灶多边形在同一坐标系合并为一个二值掩膜，作为第四通道。
3. 保留病灶外RGB、多个病灶的相对位置和同图上下文；RGB与掩膜的几何增强必须同步。
4. 同一患者的多张四通道图像仍组成患者bag，逐图六类概率在患者内等权平均。
5. 不向分类器提供人工类别名称；病灶类别存在、对象计数和Excel不作为L0首轮的额外结构化特征。
6. L0与E1作固定五折配对，估计人工轮廓辅助流程的增量价值；若无可信收益，停止该路线，不增加医院工作量。
7. 因现有轮廓存在明显诊断相关的标注存在性差异，正式结果必须附带mask-only代理审计和零掩膜分层解释。
8. 只有L0图像结果有价值，才允许对冻结C3进行一个简单、预登记的后续融合；2026始终不得用于选择路线。

## 后果

- 病灶之间和非病灶区域的信息不会因裁小图而丢失；
- 模型可利用病灶形状、范围、位置和上下文，但这些信息也可能包含人工标注流程偏差；
- L0只能称为医生辅助输入研究，不能称为全自动病灶识别；
- 13类finding和两个歧义类的处理成为明确局限，临床协议变化必须版本化，不能按结果事后调整。
