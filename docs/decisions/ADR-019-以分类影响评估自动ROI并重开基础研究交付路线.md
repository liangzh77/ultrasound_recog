# ADR-019：以分类影响评估自动ROI并重开基础研究交付路线

- 状态：Accepted
- 日期：2026-08-27
- 范围：自动超声有效视野ROI、患者级六分类、图像与临床结果、2026时间外验证

## 背景

项目负责人进一步确认，本项目需要达到完整但不过度拔高的基础研究水平，最终验收物是研究报告。`膝关节2026未标注`由甲方保留参考诊断；冻结预测交付后，甲方医生返回结构化诊断并评价结果。

现有分类实验使用人工确认的`ultrasound_rect`。该矩形表示设备画面中的超声有效视野，并非病灶边界。矩形边缘不存在唯一医学真值，人工标注也允许合理模糊，因此不能用单一IoU或覆盖率硬门代替下游诊断评价。

ADR-018仍然有效：D0及其原预登记F0/F1路线保持阴性和停止。本决策不是事后放宽D0门槛，而是因交付目标及自动ROI需求得到明确后，建立新的v2研究问题。

## 决策

1. 建立R0自动超声有效视野定位任务，以现有人工确认`ultrasound_rect`为有噪声的参考监督。
2. ROI几何指标、裁剪失败率和病例图只作描述与错误分析，不设置固定晋级阈值。
3. 自动ROI是否可用，主要通过相同患者折、相同分类模型和相同训练预算下，对比整图、自动ROI、人工ROI的患者级分类结果决定。
4. 若自动ROI分类结果与人工ROI整体接近且失败模式可接受，2026队列采用全自动流程；若自动ROI明显损害分类而人工ROI结果仍有研究价值，则向甲方申请2026 ROI并采用半自动流程。
5. 上述路线选择只使用开发队列。2026队列不用于选择全自动/半自动路线、调阈值或改模型；否则只能称为工程试用，不能称为时间外独立验证。
6. 2026预测冻结后，甲方返回患者级六分类结构化参考诊断；无法判断或存在争议的病例单独标记。
7. 28类病灶轮廓分割降为探索性附录，不阻塞自动ROI、六分类和2026验证。

## 评价解释

- 主要证据：患者级macro-F1、逐类灵敏度/F1、混淆矩阵、Top-2和校准结果的配对比较。
- 辅助证据：ROI IoU、边界偏差、裁剪失败类型及代表性可视化。
- 决策方式：综合效应大小、置信区间、逐类影响和临床可接受的失败病例，不把连续指标机械二分为“通过/失败”。

## 后果

- 自动ROI成为正式诊断流程研究，而病灶多类别分割不再占用主线资源；
- 必须生成严格OOF的自动ROI，避免ROI定位器见过外层测试患者；
- 2026仍保持标签隐藏和一次性验证地位；
- 最终报告可以给出全自动、半自动或当前条件不足三种诚实结论。
