# ADR-021：冻结自动有效视野定位但不宣称全自动诊断可用

- 状态：Accepted
- 日期：2026-08-27
- 范围：R0/R1有效视野ROI路线、L0病灶轮廓辅助、2026冻结流程

## 背景

R0严格患者隔离五折为4,543张开发图全部生成自动有效视野ROI。R1使用冻结E1分类器，只替换外层人工有效视野ROI，五折患者配对和预登记病例审阅均已完成。

自动ROI患者级macro-F1为0.2189，人工ROI为0.2155，差值+0.0034，95%CI为−0.0120～+0.0194；Top-2相同，ECE略好，逐类F1最大变化约0.03。自动ROI无漏检。87名预登记病例全部审阅，未见系统性裁掉主要超声内容；33名人工正确转自动错误与35名反向纠正大致对称。

与此同时，两套有效视野输入的绝对六分类性能都较低，损伤F1为0，不能把“ROI来源影响小”误写成“全自动诊断可用”。

## 决策

1. 后续研究和2026冻结流程采用R0自动有效视野定位，不要求医院医生补画`ultrasound_rect`。
2. 不因R1差值略为正而声称自动ROI提高诊断；结论限定为相对人工有效视野没有观察到有意义的分类损害。
3. 当前E1/R1不冻结为临床独立六分类模型，必须在最终报告保留绝对性能、损伤类失败和折间不稳定。
4. 继续已预登记L0：自动有效视野之后，医生如提供病灶多边形，则以完整有效视野RGB+同坐标二值mask、患者多图聚合研究六分类。
5. L0若无可信增益，项目不得以病灶轮廓观感或Excel强基线掩盖图像分类失败；可诚实结论为当前条件不足。
6. 2026继续隔离，待L0开发集路线闭合后才执行一次性冻结预测。

## 后果

- “医生是否要提供ROI”被拆成两个问题：有效视野矩形不需要医生提供；病灶轮廓是否值得医生提供由L0决定；
- R0可作为工程自动裁屏组件，但不能单独支持临床诊断声明；
- L0正式五折成为下一项主要训练工作，R1结果不用于修改L0类别、架构或超参数。
