# ADR-007：冻结 C3 临床数值基线并限制缺失模式用途

## 状态

Accepted。

## 日期

2026-08-02

## 背景

C0～C4 在结果未知时预登记后完成 767 名异常患者的固定五折。C3 使用 ADR-002 允许的年龄、性别和六项化验数值，macro-F1 为 0.7185，比人口学 C1 高 0.3056，五折 5/5 为正，所有类别 F1 均大于 0.10。

同时，C2 只用化验缺失模式就达到 macro-F1 0.5146；C4 把缺失指示器加入 C3 后达到 0.8050，比 C3 高 0.0865（配对 95% CI +0.0566～+0.1189）。这明确表明内部数据包含强烈的开检查流程信号。

## 决策

- 冻结 C3 为异常五分类临床单模态参考；允许字段仍严格为 `sex`、`age_years`、ESR、CRP、抗 CCP、RF、HLA-B27、尿酸；
- C3 主输入不包含显式缺失指示器、病程、日期、身份、诊断文本或 Excel 是否存在；
- C2 永久标记为工作流偏差审计，C4 永久标记为缺失模式敏感性上限；二者不得因内部成绩更高而成为核心模型；
- 不启动两层 MLP 或树模型。C3 已通过有用性门槛且折间稳定，没有“前两者明显欠拟合”的证据；
- 若未来解除图像融合阻塞，F1/F2 复用 C3 字段，比较化验遮蔽 `p=0` 与训练期 `p=0.15`，但不输入显式 missing mask；
- F0～F2 仍等待新的合格图像候选，不能用临床模型替代正常/异常图像门；
- 时间外标签继续隐藏，不能用于反向选择临床复杂度或缺失策略。

## 被拒绝的方案

### 选择分数最高的 C4

拒绝。C4 的增益满足预登记的工作流依赖判据，其可迁移性高度依赖医生开检查习惯。

### 因 C3 成绩较高立即训练 MLP 或树模型

拒绝。当前没有明显欠拟合证据；继续增加模型族会扩大开发集顺序搜索。

### 把 C2 缺失模式解释为医学诊断能力

拒绝。C2 没有读取任何化验数值，只反映哪些检查被执行。

### 直接做六分类临床模型

拒绝。正常组没有同标准 Excel，模型会把 Excel 是否存在当成正常标签。

## 后果

- C3 提供后续融合可复用、可解释且严格受控的临床输入；
- C2/C4 的阳性高分作为偏差证据进入最终报告，而不是被删除；
- 后续报告必须同时展示 C1 人口学、C2 缺失模式、C3 数值和 C4 敏感性结果；
- 当前仍没有可运行的完整图像+临床六分类主模型，盲测保持隔离。
