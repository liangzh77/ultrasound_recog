# ADR-018：D0未通过折间、类别安全与校准门并停止F0/F1

- 状态：Accepted
- 日期：2026-08-26
- 范围：异常患者五分类D0及后续F0/F1图像+Excel融合

## 背景

D0按ADR-016/017完成修订资源pilot和冻结五折。合并OOF macro-F1为0.4242，相对E2条件概率提高0.0559，配对95% CI下界0.0050；总体增益成立。但只有2/5折正向，损伤F1下降0.0648，ECE为0.3544，分别违反4/5折、任类下降不超过0.05和ECE不超过0.30的预登记门。

## 决策

D0记为预登记阴性，不冻结为异常图像模型，不启动F0/F1。禁止在当前开发集上追加骨干、聚合器、KL强度、损失、seed、重分折、事后校准或融合权重搜索。

保留D0五折OOF、attention、checkpoint、MLflow和完整阴性结果。总体macro-F1改善只作为研究发现，不覆盖折间稳定性、类别安全和校准失败。

## 后果

- ADR-016允许的受控探索路线在D0处终止；
- G0、完整六分类和2026隐藏队列决定不变；
- F0/F1保持`stopped_not_started`，不能用C3临床强信号掩盖D0失败；
- 下一次模型工作仍需新数据/直接采集元数据，或S1a/S1b形成新的临床确认监督证据并重新预登记。
