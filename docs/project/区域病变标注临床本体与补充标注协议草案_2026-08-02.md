## 为什么不能只按现有类名训练

S1显示4,346对跨类多边形重叠，9类多折支持不足；人工标注存在性本身又能以macro-F1 0.8240区分主要诊断。这意味着类名同时混合了解剖结构、病变、切面选择和标注者已知诊断后的选择。

现有名称也与标准病变不完全一一对应。EULAR-OMERACT把RA超声滑膜炎拆为灰阶滑膜增厚和滑膜内Doppler活动，并形成组合评分；“滑膜”不能在未确认时自动解释成“滑膜增生”。痛风OMERACT基本病变包括痛风石、聚集体、双轨征和骨侵蚀；泛称“结晶”不能确定是哪一种。膝OA超声可靠性研究则分别评价滑膜、骨赘、软骨和半月板异常，正常“软骨”轮廓不能自动等同于软骨损伤。[RA滑膜炎定义研究](https://pubmed.ncbi.nlm.nih.gov/28948983/)、[痛风基本病变验证](https://pubmed.ncbi.nlm.nih.gov/26329333/)、[痛风病变一致性研究](https://pubmed.ncbi.nlm.nih.gov/26472419/)、[膝OA超声可靠性研究](https://doi.org/10.1136/annrheumdis-2014-206774)。

## 建议本体

### A. 解剖定位层

候选包括骨皮质、软骨、髌韧带、股四头肌腱、内侧/外侧副韧带、内侧半月板、髂胫束、股二头肌腱、鹅足腱、半膜肌/腱和髌前浅筋膜。

用途仅为ROI内定位、切面辅助或病变相对位置，不把“是否画了某结构”直接作为诊断特征。这里尤其要确认：

- `软骨`标的是所有可见正常软骨，还是只标异常软骨；
- `骨皮质`标的是可见骨面，不能混入骨侵蚀或骨赘；
- 结构只在特定切面出现时，未出现应记`not_in_view`而不是病变阴性。

### B. 炎症活动层

优先复核滑膜血流、积液；`滑膜`必须先确认是解剖滑膜还是滑膜增厚/增生。建议目标状态分别记录，不把积液并入滑膜增厚。Doppler目标还必须记录图像模式及“信号位于滑膜内”的判定。

### C. 结构损伤层

骨侵蚀、骨赘为支持充分的候选；髌前血肿支持不足，暂缓。`软骨`只有在医生确认其表示损伤而非正常结构后，才能转入此层。

### D. 晶体沉积层

痛风石与`结晶`不能只按当前名字直接训练。医生需要把每个`结晶`实例映射为双轨征、聚集体、其他钙化或不确定；痛风石应按一致的形态定义复核。由于这两类当前只见于痛风主要诊断患者，复核尽量对诊断盲法，并加入非痛风可见负例。

### E. 囊肿/滑囊层

腘窝囊肿支持充分，可作为独立候选。囊肿、滑膜囊肿、半月板囊肿、髌下深囊炎、鹅足腱滑囊/炎支持不足或含义冲突；先确定上位类“囊性/滑囊性病变”是否临床有用，再决定保留子类还是合并。客户要求排除的是“滑膜囊肿”主要诊断患者，不自动等于必须删除所有同名局部病变对象，但当前纳入队列仅1名患者，不能独立建模。

## 每张图必须新增的状态

对进入新训练合同的每个目标，不能只有“有多边形/无多边形”。至少需要：

| 字段 | 允许值 | 含义 |
|---|---|---|
| `presence_state` | `present` | 目标明确存在；有多边形或明确图级阳性 |
|  | `absent_visible` | 对应解剖区域可见、图像质量足够、医生确认没有目标；唯一可作负例的状态 |
|  | `not_in_view` | 切面没有覆盖目标位置，不是负例 |
|  | `uncertain` | 医生无法可靠判断；训练损失mask掉 |
|  | `legacy_unknown` | 旧数据未说明是否穷尽；训练损失mask掉 |
| `annotation_scope` | `exhaustive_for_declared_targets` | 对声明目标完成逐图穷尽审阅 |
|  | `positive_only` | 只画了看到的阳性，不允许把缺失类当阴性 |
|  | `unknown` | 旧标注默认值 |
| `review_status` | `single` / `double` / `adjudicated` | 标注一致性与裁决状态 |
| `image_mode` | `B` / `PD` / `CD` / `unknown` | 灰阶、能量或彩色Doppler |
| `truncated_by_roi` | true / false | 多边形是否碰到或越过ROI边界 |

## 重叠、ROI和负例规则

- 不同类别允许像素重叠；原始实例多边形分别保存，不以绘制顺序覆盖；
- 需要语义mask时，每个目标单独一个二值通道，或按临床本体拆成不同任务头；
- 只读取人工确认ROI内像素。越界多边形与ROI求交，保留`truncated_by_roi=true`并进入复核队列；交集为空时不静默变成阴性；
- 修复无效多边形后重算bbox和面积，旧`area`字段不作为训练真值；
- 只有`absent_visible`参与负样本损失；`not_in_view`、`uncertain`和`legacy_unknown`全部mask掉；
- 用于诊断的任何病变预测必须由固定患者外层fold内训练产生OOF，禁止使用人工存在性或全数据模型预测。

## 建议的最小临床复核批次

在不修改原标注的前提下，先建立一个300～500张的伪匿名复核集，覆盖五折、六类主要诊断、B/PD模式和阳性/候选负例。建议优先问题：

1. `滑膜`到底是正常结构还是滑膜增厚；
2. `结晶`是否可拆为双轨征/聚集体/其他；
3. 积液、滑膜血流、骨侵蚀、骨赘和腘窝囊肿能否做到逐图`absent_visible`；
4. 囊肿/滑囊相关稀有类是否合并；
5. ROI边界截断实例是否仍可可靠评价。

其中至少一部分由两名医生独立复核并裁决。图级存在性报告一致率、阳性一致率和Cohen's kappa；多边形报告Dice/IoU及边界失败原因。实际张数、双标比例和一致性门槛需由临床资源确认后写入正式预登记，不能在结果出现后补设。

## 进入训练前必须回答的八个问题

1. `滑膜`的操作性定义是什么？
2. `滑膜血流`使用PD还是CD，是否要求信号位于已确认滑膜内？
3. `结晶`如何映射到双轨征、聚集体或其他钙化？
4. `软骨`是正常结构还是损伤？
5. `骨皮质`是否只表示定位结构？
6. 五个囊肿/滑囊相关名称如何建立上位和子类关系？
7. 旧数据哪些目标是逐图穷尽标注，哪些只是阳性记录？
8. 医生能否在不看主要诊断的条件下完成复核集？

八项没有形成书面答案前，本草案保持Draft；不得把它当成正式训练标签合同。
