# L0人工病灶掩膜引导患者多图六分类预登记

- 日期：2026-08-27
- 状态：运行前合同已完成执行；本文件保留结果未知时的原始预登记，结果见五折报告和病例复核
- 对照：E1人工确认有效视野RGB患者级六分类
- 配置：`configs/research/l0_lesion_guided_mean_b2.yaml`
- 决策：见[ADR-020](../decisions/ADR-020-以完整有效视野RGB加人工病灶掩膜研究辅助诊断.md)

## 研究问题

在保留一张超声图像完整有效视野和患者多图关系的前提下，增加医生人工病灶轮廓，能否改善患者级六分类？

L0估计的是“医生提供病灶轮廓后的辅助诊断流程”，不是自动病灶分割，也不代表无需医生输入的全自动系统。若全自动分类不足而L0有稳定收益，L0可作为医院补充病灶轮廓后的半自动候选；若收益很小、不稳定或主要来自标注流程偏差，则不建议增加医生工作量。

## 输入合同

每张图的输入是同一坐标系的四个通道：

1. RGB前三通道：完整的人工确认超声有效视野`ultrasound_rect`；
2. 第四通道：13类finding多边形在该有效视野内的二值并集掩膜；
3. 多个病灶保留在原图中的相对位置，不分别裁成小图，不制作逐病灶外接矩形；
4. 病灶外RGB像素全部保留，使模型仍可利用非病灶区域、组织背景和病灶间关系；
5. 类别名称不传给分类器，不把人工类别名或对象计数作为显式特征；
6. 没有纳入多边形时保留完整RGB，第四通道全零。全零只表示“当前选择规则下没有轮廓”，不能解释为医学真阴性。

有效视野RGB和掩膜先按同一矩形截取，再以同一比例和偏移letterbox到384×384。训练期翻转和仿射变换同时作用于RGB与掩膜，亮度、对比度变化只作用于RGB；掩膜始终用最近邻插值保持二值。

## 病灶类别范围

按既有S1工程角色，在分类结果未知时固定13类finding：半月板囊肿、囊肿、滑膜囊肿、滑膜血流、痛风石、积液、结晶、腘窝囊肿、骨侵蚀、骨赘、髌下深囊炎、髌前血肿、鹅足腱滑囊炎。

13类解剖结构不进入病灶掩膜；角色仍有歧义的`滑膜`和`鹅足腱滑囊`也不进入L0 v1。这个选择是工程性、保守的初始合同，不等同于医生确认的完整病灶本体。若临床确认要求修改类别，只能作为结果解释前的书面协议修订或另立研究版本，不能查看L0结果后挑选类别。

## 患者级建模

- 开发队列：固定967名患者、4,543张图、六类主要诊断和既有五个患者外层折；
- 单图编码器：EfficientNet-B2，ImageNet本地权重，输入通道由3改为4；
- 患者聚合：每张图得到六类概率后患者内等权平均；
- 训练期每名患者最多固定抽取6张图，验证和外层测试使用该患者全部合格图像；
- 类别平衡、优化器、学习率、轮数、早停、图像尺寸及资源合同与E1保持一致；
- 五折种子为`20260827 + fold`；训练与早停只使用内层训练/验证，外层测试只在最佳轮次冻结后运行一次。

因此，一名患者的多张`完整有效视野RGB + 同坐标病灶mask`图像共同决定一个六分类结果。Excel不进入L0首轮图像实验。

## 配对评价

主要比较为L0减E1，因为两者使用相同患者折、相同完整有效视野RGB和相同患者聚合，主要差别是L0增加人工二值病灶掩膜。报告：

- 患者级macro-F1及2,000次按真实类别分层的患者配对bootstrap 95%置信区间；
- 五个外层折的macro-F1及正负方向；
- 六类灵敏度、F1、混淆矩阵、Top-2和ECE；
- 预测改变病例、错误新增病例及小样本损伤类；
- 全零掩膜患者、至少一张阳性掩膜患者两组的描述性结果。

不设置机械的单一通过门。路线判断综合效应大小和区间、折间一致性、逐类损伤、病例审阅、人工工作量与标注偏差。若没有可信的患者级改善，不因病灶图看起来合理而推荐半自动流程。

## 标注存在性代理审计

掩膜准备审计已知但分类结果未知：4,543张图中2,144张有阳性掩膜、2,399张为零掩膜；967名患者中701名至少一图有阳性掩膜、266名全部为零。阳性掩膜率按诊断差异明显：正常5.7%、损伤20.2%、SPA 40.7%、RA 56.3%、OA 58.1%、GA 73.4%。

这可能同时包含真实征象差异和人工标注流程偏差。正式评价必须附加一个冻结的mask-only低维代理审计：每名患者只取“阳性掩膜图像比例、所有图平均掩膜面积比例、最大掩膜面积比例”三个特征；在每个固定外层折用训练患者拟合`StandardScaler + LogisticRegression(C=1, class_weight=balanced, max_iter=2000, random_state=20260827)`，直接预测该折外层患者，不调参、不读取RGB、类别名称或诊断相关元数据。它只量化掩膜存在性/面积本身的可分性，不参与L0调参或候选选择。L0有收益时，也必须与该代理结果、S1人工存在性偏差和病例审阅共同解释，不能直接声称模型学到了纯病灶形态。

## 与自动ROI和Excel的关系

- R1研究自动`ultrasound_rect`是否能代替人工有效视野矩形；L0研究医生病灶轮廓能否增加诊断信息，两者不是同一个ROI问题；
- L0首轮使用人工确认有效视野，是为了与E1做清晰配对；若L0有价值，最终流程再结合R1选择的有效视野来源；
- 只有L0图像结果显示可信增益后，才允许使用已经冻结的C3临床模型做一个预先固定的简单融合敏感性分析；不得搜索融合权重、骨干或额外seed；
- 若L0不增益，停止L0+C3，不以Excel强模型掩盖病灶轮廓输入无效。

## 2026时间外边界

2026队列不用于L0类别选择、训练、阈值、模型选择或路线决定。若开发集决定保留L0，甲方必须在冻结推理前按同一协议提供病灶轮廓；随后只运行一次正式患者级预测。若在查看2026预测后补画或修改轮廓，结果只能标记为补充工程分析，不冒充独立时间外验证。

## 停止规则与局限

- 资源pilot失败时，只允许修正明确的工程或资源问题并留痕，不查看外层测试性能；
- 正式五折完成后不根据外层结果修改类别、掩膜形态、边距、聚合器或超参数；
- 当前轮廓不是逐图穷尽性标注，零掩膜不是医学阴性；
- 13类finding角色尚未经过S1a正式临床双签确认；
- L0评价的是现有人工标注流程在同源开发队列中的辅助价值，不是自动病灶分割性能，也不是临床部署认证。
