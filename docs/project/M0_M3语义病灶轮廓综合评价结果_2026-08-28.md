# M0—M3语义病灶轮廓综合评价结果

## 最终结论

预登记的M0、M1、M2、M3历史回顾性比较已经完成。M1人工结构化病灶征象取得最高macro-F1 0.6351，但它同时包含医生已知病灶类别和历史标注流程信息，不能称为AI图像识别性能。M2完整ROI RGB加13类语义轮廓为0.3327，虽稳定高于纯图像M0的0.2155，却比M1低0.3024（95% CI −0.3469～−0.2562），五折均未超过M1。

M3固定加入Excel C3后为0.5676，较M2提高0.2348（95% CI +0.1958～+0.2735），五折均正向；但仍低于更简单的M0正常门控加C3异常分类对照0.6018，配对差−0.0342（95% CI −0.0578～−0.0096），仅2/5折正向。因此不把M3或当前语义轮廓模型纳入既有自动交付流程，也不在同一历史开发集继续搜索融合权重。

研究支持一个有限结论：医生按类别提供结构化病灶征象在内部数据中具有很强区分力，值得未来用统一、盲法、逐图完整的标注协议做独立第二阶段验证；目前没有证据证明现有轮廓像素模型比“类别、数量、面积”更有价值，也没有证据证明其加入Excel后优于更简单的自动图像加Excel流程。

## 固定设计

| 组别 | 每名患者输入 | macro-F1（95% CI） |
|---|---|---:|
| M0 | 完整有效视野ROI RGB，多图概率均值 | 0.2155（0.1912～0.2389） |
| M1 | 13类病灶的存在、对象数、面积比例，共39项 | 0.6351（0.6039～0.6647） |
| M2 | 完整ROI RGB＋13类可重叠mask，共16通道，多图概率均值 | 0.3327（0.2991～0.3648） |
| M0＋C3分层对照 | M0正常概率；有C3时异常条件概率只用C3 | 0.6018（0.5715～0.6318） |
| M3 | M2正常概率；有C3时异常条件概率为75% C3＋25% M2 | 0.5676（0.5360～0.5977） |

M3没有搜索权重。历史C3只覆盖767名异常患者，200名正常患者没有C3行；这种可用性与参考诊断相关，不是随机缺失。因此M3与M0＋C3均是历史工作流敏感性结果，不可直接当作前瞻性临床性能。

## 异常五分类描述性分析

在具有C3的767名异常患者中，C3单独macro-F1为0.7185，M2异常条件概率为0.3868，固定融合后的M3为0.7141。M3相较C3在痛风、脊柱关节炎和骨关节炎略有变化，但损伤F1由0.5714降至0.5235；ECE由C3的0.0475升至M3的0.1391。该分析进一步说明25%的M2权重没有形成稳定净收益。

## 后续建议

1. 保持R0＋E1＋C3的2026冻结预测和医院回表合同不变；当前M0—M3结果不得用于回写或重选2026预测。
2. 停止在现有历史数据上搜索语义轮廓网络、类别删选或融合权重，避免把诊断相关标注流程继续拟合成“研究增益”。
3. 若医院愿意开展第二阶段，优先收集少量但规范的新标注：逐图记录存在、不存在、不可见、不确定，轮廓带明确类别，标注者尽量不知道最终诊断和AI结果。
4. 新数据应独立验证M1结构化征象和M2图像轮廓路线；在独立证据出现前，M1只能作为“医生结构化征象＋流程偏倚”的内部可行性上限，不能直接交付为诊断模型。
