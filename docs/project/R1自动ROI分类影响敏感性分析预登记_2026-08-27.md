# R1自动ROI分类影响敏感性分析预登记

- 日期：2026-08-27
- 状态：已预登记，等待R0正式五折OOF
- 配置：`configs/research/r1_auto_roi_classification_sensitivity.yaml`

## 研究问题

严格患者隔离的自动有效视野ROI替换人工确认ROI后，冻结E1患者级六分类结果如何变化？

R1不重新训练诊断模型。每个外层折固定使用原E1该折的`best_formal.pt`，只把测试患者图像的人工ROI替换为R0对应外层折生成的OOF自动ROI。由此把变化主要归因于推理阶段ROI来源，而不是新架构、训练随机性或超参数。

为补齐v2计划中的三路输入比较，同时引用既有、已冻结的E0整图五折OOF作为风险对照。主要受控比较仍是“自动ROI减人工ROI”；“自动ROI减整图”只提供实际路线背景，因为两者使用的分类器训练输入不同，不解释为单独的ROI因果效应，也不新增训练。

## 冻结输入

- 患者、外层折、标签和图像：沿用967名患者、4,543图的固定registry；
- 人工ROI基线：既有E1五折OOF；
- 自动ROI：R0五个外层折的测试预测，每张图只能来自未见过该患者的ROI定位器；
- 整图风险对照：既有E0五折OOF，SHA-256为`8a0c0cb26b2211a6b59f78fa9d8b4e9c888f1f4f65cb90d3cd6ce8dceb247ee9`；
- 人工ROI OOF在评价前核验SHA-256 `a2bb7c9ea2f56dc7de8f29cebc175441cf6b7a1832684730033def86cb72aeac`；
- 分类模型：E1 EfficientNet-B2逐图概率、患者内平均，五个checkpoint及SHA-256已写入机器配置；
- 图像尺寸、letterbox、类别顺序和患者聚合与E1一致。

## 无检测处理

若R0某张图没有检测框，R1使用该张完整图像作为确定性兜底并明确计数；不人工补框、不删除患者、不根据真实诊断选择处理方法。该兜底的影响属于全自动流程实际风险。

## 评价

主要报告患者级macro-F1及其相对人工ROI的配对差异和bootstrap 95%置信区间，同时报告逐类灵敏度/F1、混淆矩阵、Top-2、ECE和预测改变病例。

不设置固定“通过线”。综合效应大小、区间、逐类影响、无检测兜底和病例审查，判断自动ROI是否足以支持全自动路线。几何IoU不参与硬判定。

## 禁止事项

- 在看到R1结果前重训分类模型或搜索checkpoint；
- 调整分类阈值、ROI置信度或后处理以改善外层结果；
- 用2026队列选择全自动或半自动路线；
- 把既有E1阴性/局限结果改写为成功。

## 后续

若R1显示自动ROI相对人工ROI的分类影响可接受，则在开发集上冻结全自动最终训练方案；若影响明显且集中在临床重要类别，则转为医院补ROI的半自动方案。两种路线均在开发集决定后才进入2026一次性验证。
