# E3 均值特征池化五折结果

## 结论

E3 证明了患者级端到端训练即使不使用可学习 attention，也能稳定优于 E1 的逐图概率平均；但它没有保留 E2 的总体性能和关键类别能力，未通过预登记门槛，因此不能冻结为图像主模型。

- 合并 967 名患者 OOF macro-F1 为 0.3010（95% CI 0.2693～0.3331）；
- 相对 E1 提高 0.0854（配对 95% CI +0.0521～+0.1225），五折 4/5 方向为正；
- 相对 E2 下降 0.0654（配对 95% CI -0.1077～-0.0232）；
- 正常、痛风、损伤 F1 分别比 E2 下降 0.0591、0.1710、0.2267，均超过最大允许下降 0.05；
- ECE 0.1245、Brier 0.8026，校准门槛通过；
- E3 无 attention 参数，等权聚合从结构上消除了单图注意力塌缩，但这不足以弥补分类性能损失。

E3 作为阴性路线完整保留，不尝试 max/top-k/mean+max 或事后调参。检查点 A2 仍无合格图像主模型，F0～F2继续阻塞。

## 预登记门槛判定

| 门槛 | 结果 | 判定 |
|---|---|---|
| macro-F1 ≥0.3463 | 0.3010 | 失败 |
| 相对E1至少+0.01且配对CI下界>0 | +0.0854，CI +0.0521～+0.1225 | 通过 |
| 至少4/5折高于E1 | 4/5 | 通过 |
| 任一类别F1较E2下降≤0.05 | 正常-0.0591、痛风-0.1710、损伤-0.2267 | 失败 |
| ECE≤0.4519 | 0.1245 | 通过 |
| Brier≤1.0291 | 0.8026 | 通过 |
| 资源、置换不变、外层隔离 | 全部通过 | 通过 |

门槛要求同时通过，因此 E3 总体失败。无 attention 权重使注意力塌缩门槛不适用；不能把“结构上无塌缩”替代成分类安全通过。

## 决策与下一步

1. E3 不晋级，不尝试事后聚合变体或超参数；
2. E1、E2、E2-R、E3均保留为不同问题的参考/阴性证据，没有一个可作为最终图像主模型；
3. 检查点A2继续以“无合格图像主模型”关闭，F0～F2继续阻塞；
4. 下一阶段不再只搜索患者bag聚合器，先审计已有28类区域/病变标注的覆盖、互斥性、患者分布和泄漏风险，再决定是否预登记病变监督或多任务图像路线；
5. 2026标签隐藏队列继续隔离。
