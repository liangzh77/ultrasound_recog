# E2 门控注意力 MIL 五折结果

## 结论

E2 在患者级六分类性能上明确优于 E1，但没有通过预先固定的注意力塌缩门槛，因此不能直接冻结为图像主模型。

- E2 OOF macro-F1 为 0.3663（患者 bootstrap 95% CI 0.3352～0.3975）；
- 相对 E1 的配对差值为 +0.1508（95% CI +0.1125～+0.1890），五折方向均为正；
- pooled 多图患者最大注意力不低于 0.95 的比例为 0.6225，高于预设上限 0.50，且 4/5 折失败；
- E2 的 ECE 从 E1 的 0.1402 上升到 0.4519，Brier 从 0.8436 上升到 1.0290，提示输出明显过度自信；
- 检查点 A2 暂不关闭。按 ADR-005 只运行一次固定强度的归一化注意力熵正则补救 E2-R；不在相同 OOF 上搜索多个强度。

本结果只用于内部模型开发，不表示可供临床独立诊断。

## 研究问题和预设门槛

研究问题：在相同 ROI 输入、EfficientNet-B2 骨干、固定患者折和训练预算下，患者级 gated Attention MIL 是否优于患者内逐图概率平均 E1。

预设门槛：

1. OOF macro-F1 至少比 E1 提高 0.01，或在相近 macro-F1 下明显改善最差类别 F1/校准；
2. 至少 3/5 折方向不差；
3. bag 顺序不变性通过；
4. 多图患者中最大注意力不低于 0.95 的比例不得超过 0.50。

前 3 项通过，第 4 项失败，因此总体门槛失败。没有因为分类结果较好而修改注意力阈值。

## 注意力审计

- 967 名患者、4,543 张唯一图像覆盖完整；24 名单图患者、943 名多图患者；
- 每位患者的注意力权重和均为 1，图像数和 fold 合同无错误；
- pooled 最大注意力均值为 0.8642，P95 接近 1；
- pooled 塌缩率为 0.6225，超过 0.50；逐折为 0.3245、0.6211、0.8148、0.6505、0.7000；
- 注意力仅是模型重要性权重，不是病变分割、因果解释或医生确认的诊断依据。

这种高度集中可能表示模型找到少数真正有诊断价值的图像，也可能表示它在利用某张图的采集或导出捷径。当前没有切面/病变定位参考标准可以区分两者，因此必须按预设门槛判失败，而不是作有利解释。

## 决策与下一步

1. E2 不直接成为图像主模型；检查点 A2 保持开放；
2. 不立即做 ConvNeXt 骨干挑战，因为它没有直接处理注意力塌缩，且会扩大同一开发集上的模型搜索；
3. 按 ADR-005 运行一次固定强度 E2-R：只增加归一化注意力 KL/熵正则，其他条件与 E2 一致；
4. E2-R 若仍未通过预设门槛，停止 Attention MIL 补救路线，不再调整正则强度；
5. 无论后续结果如何，本 E2 阳性性能、校准恶化、注意力失败和资源误停都进入最终报告。

2026 标签隐藏队列在本阶段未读取参考标准，也未用于任何方法选择。
