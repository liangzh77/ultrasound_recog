# R1自动ROI分类影响敏感性分析结果

- 日期：2026-08-27
- 状态：五折OOF与预登记病例审阅完成
- 分类器：冻结E1五折checkpoint，未重训
- 路线结论：后续有效视野定位采用R0自动ROI；这不等同于六分类模型已达到临床可用
- 决策：见[ADR-021](../decisions/ADR-021-冻结自动有效视野定位但不宣称全自动诊断可用.md)

## 研究问题与隔离

R1只把每个外层测试患者的人工确认`ultrasound_rect`替换为对应R0外层折OOF自动ROI，分类器、患者折、图像尺寸、letterbox、类别顺序和患者内平均均保持E1不变。五个R0定位器和五个E1分类器均未见过当前外层患者；2026队列未用于推理、比较或路线选择。

967名患者、4,543张图全部完成自动ROI推理，4,543/4,543图检出，0图触发整图兜底。R1合并患者OOF SHA-256为`b3c34ea1ed7371439aeb879178730bca2085e9230c8e0c6f27bcbc71ecb5655f`。

## 主要配对结果

| 指标 | 人工有效视野E1 | 自动有效视野R1 | 自动减人工 |
|---|---:|---:|---:|
| 患者级macro-F1 | 0.2155 | 0.2189 | +0.0034 |
| macro-F1 95%CI | 0.1926～0.2387 | 0.1946～0.2429 | −0.0120～+0.0194 |
| Top-2准确率 | 0.5243 | 0.5243 | 0.0000 |
| ECE | 0.1402 | 0.1377 | −0.0024 |
| 准确率 | 0.2906 | 0.2927 | +0.0021 |

配对bootstrap共2,000次，自动ROI优于人工ROI的bootstrap比例为0.657。差异区间跨0且幅度很小，证据支持“自动有效视野与人工有效视野在当前冻结分类器上的影响接近”，不支持自动ROI带来明确诊断提升，也没有显示有意义的整体伤害。

自动ROI相对既有整图E0的情境性macro-F1差为+0.0175，95%CI为−0.0195～+0.0518。该比较还包含分类器训练输入差异，只作实际路线背景，不解释为ROI因果效应。

## 折间和逐类结果

自动ROI五折macro-F1为0.2395、0.1812、0.1518、0.2317和0.1567，折均值0.1922、标准差0.0369，仍显示既有图像分类器的折间不稳定。

相对人工ROI的逐类F1变化为：正常+0.0053、RA −0.0060、GA +0.0304、SPA 0、OA −0.0093、损伤0。自动ROI的患者级损伤F1仍为0，SPA F1约0.104。这里没有出现由ROI来源造成的大幅单类恶化，但绝对分类结果远未达到可作为临床独立诊断的水平。

## 预测改变与病例审阅

- 132/967名患者Top-1发生改变；
- 33名由人工ROI正确变为自动ROI错误；
- 35名由人工ROI错误变为自动ROI正确；
- 87名预登记患者、363张图的私有联系表全部渲染并审阅，覆盖全部潜在新增错误、最大概率漂移、最低描述性IoU和稳定随机对照；
- 未发现自动框系统性裁掉主要超声内容、空框或把设备界面当成有效视野；
- 最低IoU病例多见于人工框纳入右侧刻度/黑边、两套框上下边界取法不同，或自动框比人工框更贴近实际超声画面；
- 33名潜在新增错误病例中，框差异通常较小且无一致故障模式；结合35名反向纠正，预测改变更符合弱分类器对小幅裁剪的敏感性，而非定位器系统失效。

病例图含烧录信息，只保存在Git忽略的私有目录。公开队列和摘要不含原始路径或文件名。私有manifest SHA-256为`8f28b5faaefbf72bfc1ecd7376b4b6342a79c55dfc7060e3b84fdb58ae0b0d2d`。

## 决策解释

后续开发与2026冻结流程不要求医生补充“超声有效视野矩形”，采用R0自动有效视野定位。理由是五折患者配对显示其分类影响接近人工ROI、无漏检、逐类变化小，且全量预设病例审阅未见系统定位故障。

这项决定只解决设备画面到有效超声视野的自动裁取，不代表全自动六分类已足够。R1绝对macro-F1仅0.2189、损伤F1为0，故当前E1/R1图像分类器不作为最终临床独立诊断模型。下一步按已预登记L0研究完整有效视野RGB加医生病灶二值掩膜；若L0有可信增益，可形成“自动有效视野 + 医生病灶轮廓 + 患者多图AI六分类”的辅助路线。
