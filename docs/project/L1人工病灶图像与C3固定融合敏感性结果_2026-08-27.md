## 目的和边界

L1只回答现有L0图像概率能否给冻结C3临床数值模型提供异常五分类补充信息。它不评价正常/异常门控，不是完整六分类模型，不消除L0的人工标注存在性偏倚，也不读取2026队列。

## 决策

冻结门要求差值至少+0.01、95%CI下界大于0、至少4/5折正向且任类F1下降不超过0.05。前三项失败，只有逐类最大下降限制通过。因此：

1. 关闭L0+C3路线，不搜索其他权重、阈值、骨干或seed；
2. 不要求医院为2026队列补画病灶轮廓；
3. L0保留为“完整RGB+人工病灶mask在同源开发集有总体增益、但受强标注偏倚限制”的研究结果，不作为最终输入流程；
4. 2026研究预测回到已预登记的最简路线：R0自动有效视野、冻结E1图像六分类和冻结C3分层概率，同时明确开发集图像绝对性能不足，预测只用于时间外研究复核。
