# M2分类别语义轮廓患者六分类五折结果

## 阶段结论

M2固定五折完成。模型为每张完整有效视野ROI同时读取RGB和13个可重叠的分类别病灶mask，共16通道；保留病灶外像素、同图病灶相对位置和患者多图，患者级按多图概率均值判断六分类。M2 macro-F1为0.3327（95% CI 0.2991～0.3648），高于M0/E1纯ROI图像0.2155；配对差为+0.1172（95% CI +0.0799～+0.1557），五折均为正向。

因此，历史人工语义轮廓作为图像附加通道确实改善了纯图像基线。不过M2仍明显低于M1人工结构化征象0.6351，尚不能证明轮廓形状、图像纹理和空间关系提供了超过“病灶类别、数量、面积”的独立增量。M2与M1的正式配对区间在冻结的M0—M3综合评价中统一计算。
