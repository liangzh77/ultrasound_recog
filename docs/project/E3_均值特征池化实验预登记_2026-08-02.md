# E3 均值特征池化实验预登记

## 状态

实现和输入合同已验证；资源 pilot 已按冻结合同通过，正式结果仍未知。本文件的研究问题与正式门槛在生成任何 E3 MLflow run、权重或 OOF 前冻结。

## 研究问题与假设

研究问题：E2 的患者级性能增益是否主要来自患者级端到端训练，而不需要可学习且会塌缩的 attention 权重？

预设假设：对同一患者的有效图像 embedding 做等权平均，再使用一次患者级线性分类头，可以保持 E2 相对 E1 的大部分收益，并消除可学习 attention 引起的单图集中风险。

## 唯一方法变化

E3 与 E1 使用相同的：

- 967 名开发患者、4,543 张图像和固定患者级五折；
- 人工确认 ROI、384×384 等比例 letterbox、不加 ROI 边距；
- EfficientNet-B2 ImageNet-1K 本地预训练权重；
- 最多随机 6 张训练图、推理读取患者全部图像；
- 增强、优化器、学习率、类别平衡、早停、AMP 和资源门槛。

唯一变化为患者聚合：E1 对逐图 softmax 概率做平均；E3 对逐图 encoder embedding 做等权平均，再经过 dropout 和一个患者级线性分类头。padding 不参与平均，bag 顺序不影响结果。E3 没有 attention 参数，也不把等权系数解释为病变定位。

## 正式五折晋级门槛

以下条件必须全部通过：

1. 合并 OOF macro-F1 不低于 0.3463，即不比 E2 的 0.3663 低超过 0.02；
2. 相对 E1 macro-F1 至少提高 0.01，且患者配对 bootstrap 95% CI 下界大于 0；
3. 至少 4/5 个 outer fold 的 macro-F1 高于同折 E1；
4. 任一类别 F1 相对 E2 下降不超过 0.05；
5. ECE 不高于 E2 的 0.4519，multiclass Brier 不高于 E2 的 1.0291；
6. bag 顺序不变、padding 忽略、全图推理覆盖与外层隔离测试通过；单模型运行小于12小时目标、绝不超过23.5小时硬限制。

E2 只作为性能和类别安全参照，不因其 attention 失败而降低 E3 门槛。不得查看 2026 隐藏参考标准或根据中间 fold 改变配置。

## 停止规则与后续

- pilot 资源门槛失败：记录失败并修复明确的工程原因；不得改研究输入或模型以追分；
- 正式门槛失败：保留全部权重、OOF、MLflow和阴性结论，停止 E3；
- 正式门槛全部通过：以独立阶段报告和新 ADR 关闭 A2，然后才允许实现 F0～F2；
- 不自动尝试 max/top-k/mean+max、新骨干或额外超参数。

2026 标签隐藏队列在本阶段继续隔离。本预登记只涉及内部患者级六分类图像模型，不声明临床部署能力。
