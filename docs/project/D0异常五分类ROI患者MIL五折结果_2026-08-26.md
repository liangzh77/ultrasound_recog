# D0异常五分类ROI患者MIL五折结果

## 结论

D0在767名异常患者的严格五折OOF上得到macro-F1 0.4242（分层bootstrap 95% CI 0.3838～0.4630），相对冻结E2条件概率提高0.0559，配对95% CI为0.0050～0.1055。总体增益及配对不确定性门通过，但预登记要求全部门同时通过；D0因以下三项失败而判定阴性：

1. 只有2/5折优于E2条件概率，低于4/5；
2. 损伤F1从0.4615降至0.3967，下降0.0648，超过0.05类别安全上限；
3. ECE为0.3544，高于0.30。

因此按预登记和[ADR-018](../decisions/ADR-018-D0未通过折间类别安全与校准门并停止F0F1.md)，不启动F0/F1，不搜索第二骨干、KL强度、聚合器、随机种子或校准方案。该结果不改变G0、完整六分类或2026隐藏队列的停止/隔离状态。
