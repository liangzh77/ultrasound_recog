# R0-E1-C3冻结研究预测模型卡

- 版本日期：2026-08-27
- 状态：开发路线和2026一次性预测已冻结；时间外参考诊断尚未返回
- 类型：研究预测流水线模型卡，不是医疗器械说明或临床部署许可

## 预期用途

本流水线用于膝关节超声医院合作研究：对一名患者的多张超声图像自动提取有效视野，输出患者级六分类图像概率；在有同结构临床数值时，同时输出固定分层多模态概率，交由医院医生复核研究效果。

允许用途限于研究报告、误差分析和甲方复核。禁止将Top-1直接作为诊断结论、自动替代医生、据此治疗或在没有本地验证的机构部署。

## 输入与输出

| 部分 | 合同 |
|---|---|
| 图像 | 同一患者1张或多张膝关节超声图像；2026实际为每人2～30张 |
| 自动有效视野R0 | 五个外层折检测器各给出最高置信框，对可用框逐坐标取中位数；全部无检测才整图兜底 |
| 图像六分类E1 | 五个冻结E1分别逐图推理、患者内平均，再对五个患者概率等权平均 |
| 临床C3 | 性别、年龄、ESR、CRP、抗CCP、RF、HLA-B27、尿酸；排除身份、诊断、病程、日期及显式缺失指示器 |
| 分层公式 | `P(正常)=P_E1(正常)`；异常类为`(1-P_E1(正常))×P_C3(d|异常)` |
| 输出 | 图像单模态和分层多模态各自的Top-1、Top-2、六类概率、低置信提示，以及图像级自动ROI |

医生病灶多边形不是冻结输入。L0保留完整RGB与同坐标病灶mask的研究已经完成，但因强标注偏倚和融合失败关闭。

## 开发证据

- 开发队列967名患者、4,543张图，固定患者级五折，数据指纹`62ecb01c4d77ec0012704611ecc8d18ef51ebb4e0ea744fb3896948829f0b675`；
- E1人工有效视野患者级macro-F1为0.2155；R1自动有效视野为0.2189，自动减人工为+0.0034，95%CI −0.0120～+0.0194；4,543/4,543图检出，病例审阅未见系统裁剪故障；
- C3仅在767名异常患者的五分类中验证，macro-F1为0.7185，95%CI 0.6836～0.7518；它不是完整六分类结果，且人口学与化验缺失流程存在明显偏差；
- 患者级Attention MIL E2曾达到macro-F1 0.3663，但注意力塌缩和校准失败，未进入冻结流水线；不能把E1称为开发集最佳图像模型，它是复杂度和可审计性约束下的保守冻结组件。

## 已知限制与失效模式

1. 图像单模态开发性能低，SPA、损伤和正常等类别曾出现明显不足；输出不适合独立诊断。
2. 自动有效视野解决的是设备画面到超声内容区域，不是病灶分割；框边界也不存在唯一人工答案。
3. C3使用真实诊疗流程中的化验，内部成绩受人口学构成、检查选择和缺失流程影响，跨时间、跨医院可迁移性未知。
4. 开发正常组没有与异常组同标准临床表，因此完整分层六分类缺少同源开发集直接验证；2026是其首次冻结时间外评价。
5. 多张图采用等权平均，未建模切面完整性或重复图；采集数量和设备界面可能携带非医学信号。
6. 低置信提示只是复核优先级，不构成拒识安全系统；当前没有建立临床工作流阈值。

## 评价与变更控制

医院参考诊断回收后，按冻结R3程序同时报告两个输出的macro-F1及bootstrap区间、逐类灵敏度/F1、混淆矩阵、Top-2、Brier、ECE、置信亚组和配对差。不得依据结果切换输出、改ROI、改公式、改阈值或重训；后续改进必须另立版本并标注为补充分析。
