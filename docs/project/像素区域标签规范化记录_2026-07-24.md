# 像素区域标签规范化记录（2026-07-24）

## 目的

像素区域标签应描述图像中的解剖结构或病变，不应包含患者的主要诊断。主要诊断由患者所在疾病目录和后续研究 manifest 表达。

例如：

```text
OA骨皮质 → 骨皮质
RA骨皮质 → 骨皮质
GA骨皮质 → 骨皮质
SPA-骨皮质 → 骨皮质
N骨皮质 → 骨皮质
```

否则分割标签本身已经带有疾病答案，会造成标签泄漏，并把同一种结构人为拆成多个小类别。

## 规范化规则

1. 先修复已确认的错别字：
   - `内测` → `内侧`
   - `股二头肌建` → `股二头肌腱`
   - `SPA-斌下肾囊炎` → `髌下深囊炎`
2. 去除疾病前缀：
   - `N`
   - `RA`
   - `OA`
   - `GA`
   - `SPA-`
   - `损伤-`
   - `滑膜囊肿-`
3. 合并确定是同一结构的不同写法：
   - `髌骨前浅筋膜` → `髌前浅筋膜`
4. 不根据疾病目录给无前缀标签重新补前缀。
5. 原始 JSON 不批量覆写；规则应用于派生训练数据。
