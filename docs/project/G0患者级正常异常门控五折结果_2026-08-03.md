# G0患者级正常/异常门控五折结果

## 结论

G0证明患者ROI图像中存在较强的正常/异常区分信号，但没有达到预登记的内部稳定性和绝对校准要求，因此正式判定失败并停止候选搜索。

- 967名患者OOF ROC-AUC 0.8672，患者分层bootstrap 95% CI 0.8431～0.8898；
- 异常灵敏度0.9061、正常特异度0.5350、macro-F1 0.7293，三项均通过；
- 仅3/5折ROC-AUC≥0.75，低于4/5门槛；fold 2/3 AUC为0.6170/0.6221；
- 校准后ECE 0.1292，高于0.10；Brier 0.1406通过，且两者均较校准前改善；
- 943名多图患者注意力塌缩率0.0032，通过≤0.50门槛；
- 五折资源和记录合同全部通过，单折最长0.7536小时、峰值保留显存最高1.3926GB；
- 按[ADR-014](../decisions/ADR-014-G0未通过折间稳定性和校准门槛并停止候选搜索.md)，不训练第二候选、不放宽门槛、不启动融合或2026盲测。
