# 标注工具定位与启动说明

## 文档目的

本文记录 2026-07-24 对项目标注相关程序的调查结果，解决以下问题：

- 像素级手动/半自动标注程序在哪里、如何启动；
- 项目根目录的 `annotation_viewer.py` 与 ISAT 有什么区别；
- 当前自动标注模型演示界面是什么、能否替代人工标注；
- 标注数据和超声有效视野裁剪信息分别保存在哪里。

## 结论

项目目前涉及三种不同用途的界面，不能互相替代：

| 工具 | 位置 | 主要用途 | 是否能编辑像素级标注 |
|---|---|---|---|
| ISAT with Segment Anything | `C:\liangz77\python_projects\ISAT_with_segment_anything` | 手动画多边形、SAM 半自动分割、选择区域类别、修改并保存标注 | 是 |
| 项目标注查看与 ROI 编辑器 | 根目录 `annotation_viewer.py` | 查看已有多边形标注，手动或自动框选超声有效视野 | 否 |
| ROI 多边形自动标注演示 | `tools/16_demo_roi_poly_seg_tk.py` | 加载当前 Mask R-CNN 权重并展示模型预测 | 否，仅预测和展示 |

用户记忆中“手动或自动标注像素区域，并指定区域类型”的程序是 **ISAT**。它不是当前仓库的一部分，而是保存在本机另一个源码目录中的独立工具。

用户记忆中“划区域进行剪切”的功能对应根目录的 `annotation_viewer.py`。这里的“裁剪”是记录超声有效视野矩形，并不真正生成裁剪后的图片。

## 一、启动像素级标注程序 ISAT

### 本机位置和环境

- 源码目录：`C:\liangz77\python_projects\ISAT_with_segment_anything`
- 程序入口：`C:\liangz77\python_projects\ISAT_with_segment_anything\main.py`
- Conda 环境：`isat_env`
- 本机环境状态：
  - Python 3.8.20
  - PyQt5 已安装
  - PyTorch 2.4.1 + CUDA 11.8
  - CUDA 可用
  - ISAT 主窗口已通过离屏方式验证，可正常初始化

### 推荐启动方式

在 PowerShell 或 Conda Prompt 中运行：

```powershell
conda activate isat_env
cd C:\liangz77\python_projects\ISAT_with_segment_anything
python main.py
```

如果当前终端不方便激活 Conda 环境，可以直接运行：

```powershell
conda run -n isat_env python C:\liangz77\python_projects\ISAT_with_segment_anything\main.py
```

当前本机使用的是源码版 ISAT。`isat_env` 中没有安装 PyPI 包 `isat-sam`，因此直接执行 `isat-sam` 会找不到命令。官方 Pip 版本的安装和启动命令是：

```powershell
pip install isat-sam
isat-sam
```

本机已有可工作的源码和专用环境，无需为了启动现有程序重复安装。

### 打开项目标注数据

ISAT 启动后，使用“打开图片目录”选择一个患者目录，例如：

```text
C:\liangz77\python_projects\github_projects\ultrasound_recog\workspace\data\raw\膝关节已标注\损伤\901196782_母嘉虹
```

患者目录中包含：

- 超声图片；
- 与图片同名的 ISAT JSON 标注；
- `isat.yaml` 区域类别配置；
- 部分目录还包含导出的 `mask/`。

ISAT 打开目录时会自动读取该目录下的 `isat.yaml`，从而显示项目现有的区域类别。

### ISAT 负责的功能

- 手工点击或拖动画出多边形；
- 使用 SAM 点提示或矩形提示进行半自动分割；
- 为区域选择解剖结构或病理类别；
- 编辑、移动、删除和重绘已有区域；
- 对多边形执行合并、相减、相交等操作；
- 保存为项目现有的 ISAT JSON 格式。

## 二、启动项目内的标注查看与 ROI 编辑器

程序入口位于仓库根目录：

```text
annotation_viewer.py
```

启动命令：

```powershell
cd C:\liangz77\python_projects\github_projects\ultrasound_recog
python annotation_viewer.py
```

本机默认 Python 已具备 PySide6、OpenCV 和 NumPy，界面已通过离屏方式验证，可正常初始化，并能读取 7 个疾病目录。

首次运行时如果还没有类别缓存，程序会扫描全部 JSON 收集类别，可能需要等待十几秒。

### 该工具负责的功能

- 在图片上叠加显示已有 ISAT 多边形及类别名称；
- 手动画出超声有效视野矩形；
- 自动框选当前图片的超声视野；
- 批量自动框选全部图片；
- 调整矩形边界并撤回或恢复；
- 使用“未裁剪”筛选完全没有裁剪框的图片；
- 使用“未确认”生成已有自动裁剪框、但尚未人工确认图片的固定快照。

### “裁剪”的实际含义

该工具不会修改原图，也不会生成裁剪后的图片。确认裁剪后，它只会在同名 JSON 中记录：

```json
{
  "ultrasound_rect": {
    "x1": 0,
    "y1": 0,
    "x2": 100,
    "y2": 100,
    "width": 100,
    "height": 100
  },
  "ultrasound_rect_reviewed": true
}
```

训练和推理脚本在内存中根据 `ultrasound_rect` 动态裁剪有效超声视野。这样可以去掉设备界面、文字和刻度，同时避免额外保存一套裁剪图片。

“自动框选全部”写入的裁剪框会设置
`ultrasound_rect_reviewed = false`。每次启用“未确认”时，程序会把当时全部未确认
图片保存为一份固定列表快照。在该快照中打开一张图片就会写入
`ultrasound_rect_reviewed = true`，但图片不会从列表中消失，仍可用上下键返回检查。
文件名使用颜色区分状态：橙色表示未确认，绿色表示已确认，灰色表示未裁剪；
鼠标悬停也会显示文字状态。关闭“未确认”后再次启用，会按最新 JSON 状态重新生成
快照，已经查看确认过的图片将不再进入新快照。

当前大类处理完后，程序会自动加载后续大类、跳过快照中没有图片的大类，
继续定位下一张。调整并保存裁剪框仍会更新矩形，但不会从本轮快照中移除该图片。

自动框选会为上、下、左、右边界分别保存若干条候选线。调整时，在目标边界对应的
区域点击希望使用的位置，程序会一次跳到距离点击位置最近的有效候选线，不需要再按
候选顺序逐条点击；如需候选线之间的位置，仍可拖动控制点进行微调。

该界面只能查看已有像素级多边形，不能新增或修改解剖结构多边形；这类操作仍应使用 ISAT。

## 四、项目和模型当前状态

根据现有项目文档和实际数据：

- 疾病类别：7 类；
- 患者：730 名；
- 图片：6876 张；
- 有多边形标注的图片：3420 张；
- 原始细粒度区域类别：84 类。

当前实验为：

```text
workspace\experiments\active\exp_2026-04_roi_poly_seg
```

当前路线是：

1. 使用 `ultrasound_rect` 统一超声有效视野；
2. 在 ROI 内训练多边形区域自动标注模型；
3. 自动标注稳定后，再将区域结果用于疾病分类。

目前正式训练后的验证结果约为：

- global precision：0.3226；
- global recall：0.1919；
- 匹配区域 mean IoU：0.7406；
- 匹配区域 mean Dice：0.8468。

模型命中后的区域形状质量较好，但漏检仍然明显，并出现一定过拟合，因此当前自动预测还不能完全替代人工标注和复核。

## 五、已发现的文档差异

`docs/project/数据集说明.md` 将标注描述为 LabelMe JSON，但实际文件和项目其他文档均表明主要格式是 ISAT：

- JSON 的 `info.description` 为 `ISAT`；
- 标注对象位于 `objects`；
- 类别字段为 `category`；
- 多边形字段为 `segmentation`；
- 患者目录包含 `isat.yaml`。

因此，后续理解和处理现有标注时，应以 ISAT 格式为准。LabelMe 仅是 ISAT 可转换的外部格式之一。
