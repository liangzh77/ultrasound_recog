# M1分类别病灶征象患者六分类五折结果

## 阶段结论

M1固定五折完成。只读取13类人工病灶轮廓的患者级存在性、对象总数和总面积比例，不读取任何RGB或Excel，六分类macro-F1为0.6351（95% CI 0.6039～0.6647），明显高于M0/E1图像基线0.2155；五个fold均为正向。

该结果证明M1是必要的正式对照：医生提供的结构化病灶征象及历史标注流程本身已经携带很强诊断信息。它不证明AI从超声像素识别疾病，也不能区分真实医学特异性、检查切面选择、非穷尽标注和标注者可能已知诊断造成的偏差。后续M2必须同时与M0和M1比较；若M2不能超过M1，就没有证据表明完整像素、形状和空间关系提供了独立增量。

## 固定输入

每名患者共39项：13类分别计算是否出现、患者全部图像中的有效多边形对象数，以及分类别二值并集阳性像素总数除以`图像数×384×384`。不同类别重叠分别保留；同类重叠面积只计一次，对象数逐个计数。所有标准化只在外层训练患者拟合，外层测试患者从未参与预处理或模型拟合。

## 与既有S1的关系

S1仅使用13类病灶是否出现时macro-F1为0.6087；M1增加对象数和面积后为0.6351，增幅约0.0264。大部分可分性已经存在于类别名称/存在性，数量和面积只提供有限额外信息。M1因此更接近“医生结构化征象和标注行为的诊断上限”，不是AI读取轮廓形态的结果。
