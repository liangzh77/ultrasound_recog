# H0：G0折间异质性与非医学代理关联审计结果

## 结论

H0按预登记完成，正式结果落入两个允许解释：`external_acquisition_export_heterogeneity`和`medical_edge_control_association`。

这表示：G0总体错误与全部六组代理都有中等可预测关系；其中只有ROI外/采集导出代理和ROI边缘医学内容控制同时与既有代理OOF概率稳定相关。它不证明G0直接利用了ROI外信息，也不证明任何因果来源。五折本身不能被这些代理稳定识别，未见预设意义上的广泛fold分布偏移。

G0继续保持停止状态；不按代理删除、重加权患者，不恢复第二候选或F0～F2融合。

## 综合解释

### 外部采集/导出异质性

`outer_nonmedical`同时通过总体错误预测和H0-C。该组包含原图几何、边框与ROI外像素，G0只读ROI，不能直接看到ROI外像素。因此允许结论是“外部采集/导出流程与G0结果共享关联”，而不是“G0使用了ROI外捷径”。潜在共同原因可能是设备、操作者、切面、导出批次或患者构成，但当前没有直接元数据，不能区分。

### 医学边缘控制关联

`roi_edge_visible_control`也同时通过总体错误预测和H0-C。ROI边缘对G0可见且可能含医学组织，所以它是阳性/医学内容控制；不能称非医学捷径。

### 未通过的解释

- 图像数、ROI长宽比和ROI分辨率能够预测总体错误，但没有同时通过H0-A或H0-C，不满足预登记的综合关联；
- 原图尺寸/导出能够预测总体错误，但H0-A和H0-C未通过；外部解释由更完整的ROI外组支持；
- 没有测得可识别的整体fold分布偏移；
- 结果不支持因果、患者剔除、代理校正、阈值调整或G0复活。
