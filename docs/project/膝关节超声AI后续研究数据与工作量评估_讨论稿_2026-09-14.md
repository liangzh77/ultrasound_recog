# 膝关节超声AI后续研究数据与工作量评估

## 当前研究基础与结论

我们已完成现有数据下的阶段性训练、比较和分析。早期分割研究使用约3,420张标注图像；当前患者级研究纳入967名患者、4,543张图像。两阶段统计范围不同，不能相加。

本阶段结论是：现有数据、标注和已测试方法下的整体效果不足以支持预期的病灶自动定位、轮廓及类型识别与疾病判断用途，不支持采用该全自动路线。这是当前已完成研究的结论。

本轮对照中识别效果最好的是“医生标注病灶类别和多边形，AI汇总患者多张图像中的病灶类别、数量及面积进行疾病判断”（M1），内部验证约70%的患者分类正确，尚需独立验证其实际应用效果。

## 研究发现数据缺口

早期合并细分类别后分割指标改善，提示类别定义与样本分散影响训练。后续审计发现，28类标签中9类独立病例不足、3类有限；积液有488名患者标注，部分稀有病灶仅1～12名。仅1名阳性患者无法同时提供独立的阳性训练与验证病例。

## 增加维度可能扩大数据需求

模型需要学习不同患者、切面和严重程度下的病灶特征。同一患者的相似图不能替代独立病例；未标注也不能直接视为阴性。新增病灶或严重程度会分散样本，但左右侧等字段可在原图补充。模型大小、字段数与所需图数之间没有固定换算公式。

## 每种病灶的标注需求

建议按以下总量准备每种病灶的首轮训练与验证数据，合格的现有标注可计入，不要求全部新增：

| 每种病灶所需数据 | 建议数量 | 标注要求 |
|---|---:|---|
| 独立阳性患者 | 300～500名 | 覆盖不同大小、严重程度和常见切面 |
| 每名阳性患者图像 | 3～5张 | 病灶可见且有信息差异，标明类别并画轮廓，不用相似图片凑数 |
| 阳性标注图像合计 | 约900～2,500张 | 与患者对应，保留完整超声有效视野 |
| 明确阴性或容易混淆的患者 | 另100～200名 | 提供对应部位清晰可见的图像，确认目标病灶不存在；其他病灶如实标注 |

其中约20%的患者预留独立测试，约含60～100名阳性患者；同一患者的全部图像归入同一数据集，测试数据不参与训练、调参和模型选择。

300～500名是覆盖主要表现并留出独立评价病例的工程起点，尚非已验证的成功门槛。积液现有488名患者标注，数量接近该预算，重点需复核质量与完整性；稀有病灶则需定向补充。研究目标是检验轮廓与类型识别能否达到双方认可的水平，不能承诺达到数量即可成功。

若暂按现有13类病灶计算，阳性需求合计为**3,900～6,500**个“患者—病灶”记录、**11,700～32,500**个“图像—病灶”记录，尚未计入阴性数据。同一患者或图像可包含多种病灶，因此以上不是去重后的实际人数或图片数；明确阴性病例也可按各病灶状态复用，最终以确认的病灶词典逐类核算。

## 新增工作与人力投入

新方案带来的增量工作。

1. 医生：采集3900名患者（每种病灶300名）的11700张图象，确认新增及歧义标签的定义，定向补充缺口病例；对需补标的图像增加切面、左右侧、质量及完整病灶状态，复核或补画轮廓，按需补充严重程度和测量值；完成新一轮双人标注、分歧裁决及新增病例诊断核实。
2. 程序：增加切面、左右侧、质量等尚未支持的录入字段，按需增加严重程度和物理测量功能；将已有语义复核流程扩展到新字段及双人轮廓复核，并对接训练数据读取。
3. 训练：检查并接入新增数据，训练切面与质量模型；按确认后的病灶词典和标注状态适配、重训现有检测分割模型。将AI预测的病灶信息接入已有患者级分类流程，临床字段变化时调整融合；复用现有评价程序完成新一轮对照、交叉验证、误差分析和独立验证。
4. 交付：将新模型及新增结果接入既有展示界面，测试新增和受影响的流程，更新相应操作说明并补充本轮研究报告。
