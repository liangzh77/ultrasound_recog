# 患者级诊断基础研究与2026验证计划 v2.0

- 日期：2026-08-27
- 状态：已确认，开始实施
- 研究定位：具备完整研究闭环的基础水平医院合作研究，不追求架构堆叠或临床部署声明
- 最终验收物：研究报告、冻结的2026患者级预测及甲方复核结果

## 一、研究目标

围绕五个问题形成连续证据：

1. 患者级多图学习相对逐图汇总带来什么影响；
2. 自动超声有效视野ROI相对人工ROI会怎样影响患者级诊断；
3. 图像与Excel联合结果相对图像单模态有何增益和局限；
4. 冻结流程在2026时间外队列上的实际表现如何。
5. 医生人工提供病灶轮廓后，在保留完整有效视野和患者多图的条件下，是否能改善六分类。

既往E0～D0结果全部保留，阴性实验不重写。v2新增工作的依据是甲方确认了自动/半自动交付路径和基础研究定位。

## 二、任务边界

### 主线

- 患者级六分类主要诊断：正常、RA、GA、SPA、OA、损伤；
- 自动`ultrasound_rect`定位；
- 完整有效视野RGB加人工病灶二值掩膜的辅助诊断对照；
- 图像单模态结果；
- 异常患者Excel五分类及分层六分类结果；
- 2026时间外冻结预测与甲方结构化复核。

### 探索性附录

- 28类病灶/征象多边形分割；
- 切面识别；
- 注意力图和病灶轮廓可视化。

探索性任务可以报告已有发现，但不阻塞主线，也不继续进行无边界的模型搜索。

这里的“28类病灶/征象多边形分割”仍是探索性；L0不训练28类分割器，而是把现有人工finding轮廓的二值并集作为完整有效视野RGB的辅助通道，研究医生辅助输入对患者级诊断的影响。

## 三、自动ROI研究设计

`ultrasound_rect`是超声有效视野矩形，边界允许合理模糊。R0先训练或建立自动定位器，并按患者隔离生成OOF自动ROI。不得让ROI定位器在训练中见到当前外层测试患者。

随后在相同患者折和相同分类配置下比较：

| 输入 | 作用 |
|---|---|
| 原始整图 | 无ROI处理的风险对照 |
| OOF自动ROI | 全自动候选流程 |
| 人工确认ROI | 半自动流程及参考上限 |

ROI IoU、坐标偏差和失败率只作描述，不设置固定硬门。路线判断以患者级分类差异为主，并结合逐类表现、置信区间和典型失败病例。

## 四、患者级诊断与多模态

六分类始终包含正常。由于正常组没有同标准Excel，分层公式保持不变：

```text
P(正常) = P_image(正常)
P(异常疾病 d) = (1 - P_image(正常)) × P_image+clinical(d | 异常)
```

临床C3继续作为异常五分类强基线；缺失模式模型只作偏差证据。v2最多采用一种预先固定的简单晚期融合，不重新进行大规模骨干、聚合器、seed或权重搜索。

### 人工病灶轮廓辅助分支

L0不把每个病灶裁成独立小图。每张图保留完整人工确认有效视野RGB，将该坐标系内所有纳入病灶多边形合并成一个二值第四通道；病灶外RGB和多个病灶之间的位置关系均保留。同一患者多张四通道图像继续作患者级聚合。首轮只和E1图像模型配对；有可信图像增益后，才允许与冻结C3做一个简单融合敏感性分析。

现有掩膜存在率与诊断明显相关，且零掩膜不代表医学真阴性。因此L0必须同时报告mask-only代理审计、零掩膜分层和病例审阅，其结论限定为“当前人工轮廓辅助流程”的效果。

## 五、2026时间外验证合同

1. 全自动/半自动路线在开发队列上决定；
2. 冻结代码、配置、权重、类别顺序、预处理和输出格式；
3. 对225名患者生成图像单模态与图像+Excel结果；
4. 输出Top-1、Top-2、六类概率、低置信度标记和ROI结果；
5. 甲方返回六分类主要诊断；无法判断或争议病例单列；
6. 只生成一次正式时间外统计，不以该结果反向选择本轮模型。

若甲方先查看结果后要求切换ROI路线，则后续结果明确标记为工程试用/补充分析，不冒充独立时间外验证。

## 六、最小评价集

- 主指标：患者级macro-F1；
- 次要指标：逐类灵敏度/F1、混淆矩阵、Top-2、一个校准指标；
- 不确定性：患者级bootstrap 95%置信区间；
- 自动ROI附加描述：IoU、边界偏差、裁剪失败类型和病例图；
- 所有结论同时报告整体结果与损伤等小样本类别结果。

## 七、实施顺序

1. R0数据审计：确认人工矩形、患者折、图像版式及2026输入范围；
2. 建立单类别自动有效视野定位基线，并生成五折OOF ROI；
3. 进行整图/自动ROI/人工ROI分类影响比较；
4. 进行完整有效视野RGB与RGB加人工病灶掩膜的患者级配对比较；
5. 根据开发集证据冻结全自动、病灶轮廓辅助或条件不足路线；
6. 只有相应图像分支有价值时，生成图像单模态与冻结C3的简单分层多模态结果；
7. 执行2026一次性预测；
8. 接收甲方结构化真值并完成研究报告。

## 八、停止与控制

- 不因几何边界存在合理差异而机械否决自动ROI；
- 不以2026结果选择本轮ROI路线；
- 不重新解释既往未通过预登记的实验为成功；
- 不在没有新研究问题时继续增加分类架构；
- 若自动和人工ROI分类均不足，允许报告“当前条件不足”，不强行形成部署结论。
- 若人工病灶掩膜没有可信增益或收益主要由标注存在性代理解释，停止该分支，不要求医院增加轮廓工作量。
