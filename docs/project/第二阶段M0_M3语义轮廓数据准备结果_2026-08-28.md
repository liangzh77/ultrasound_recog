# 第二阶段M0—M3语义轮廓数据准备结果

## 结论

历史语义病灶轮廓已按预登记完成确定性准备。967名开发患者、4,543张纳入图像全部有一行隐私安全manifest记录；13类病灶分别保存为独立、允许重叠的二值mask，完整有效视野RGB不在本步骤复制或裁成病灶小图。该数据可用于M1患者级结构化征象和M2完整ROI RGB加13类语义通道实验。

这只是工程与支持度检查，不改变历史标注的解释边界：全零或某类零通道只表示历史标注未观察到，不是医生确认的医学阴性。

## 表示与验证

- 类别间重叠不互相覆盖，同一像素可同时在多个类别通道为1；
- 同类别同图多个多边形在面积上取二值并集，在对象数中分别保留；
- 所有mask与完整有效视野使用相同384像素letterbox坐标；
- 稀疏manifest只列实际非零通道，加载时按冻结类别顺序恢复其他零通道；
- 加载器逐文件校验SHA-256，并要求图像键与4,543张registry完全一致；
- M2 fold 0 dry-run确认训练/验证/测试为618/155/194名患者和2,929/719/895张图，外层测试不参与训练或早停。
