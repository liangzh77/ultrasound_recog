# C0～C4 临床五折基线与缺失偏差结果

## 结论

在 767 名异常患者的内部固定五折中，允许的临床数值 C3 是一个有信息且折间稳定的异常五分类基线，但人口学构成和化验缺失模式都携带很强的类别信号。显式加入缺失指示器的 C4 分数最高，却按预登记只能解释为工作流偏差敏感性结果，不能取代 C3 成为核心临床输入。

- C3 macro-F1 0.7185（95% CI 0.6836～0.7518），比 C1 年龄/性别高 0.3056（配对 95% CI +0.2697～+0.3417）；
- C3 五折全部高于 C1，五类 F1 均大于 0.10，最低为 SPA 0.4719，通过全部预设有用性门槛；
- C2 仅用六项化验是否缺失即得 macro-F1 0.5146，比 C0 高 0.4130，明确确认实质工作流偏差；
- C4 比 C3 高 0.0865（配对 95% CI +0.0566～+0.1189），满足“显著依赖缺失工作流”的预设判据，因此不晋级；
- C1 仅年龄和性别已达 macro-F1 0.4129，且痛风 F1 0.6297，说明当前队列人口学构成也会抬高内部成绩。

C3 冻结为后续异常五分类临床参考输入，但不是可独立部署的临床诊断模型。正常组无同标准 Excel，本报告也不是患者级六分类结果。

## 偏差解释

1. 痛风组在当前数据中全部为男性，C1 的痛风灵敏度达到 0.9690；这更可能是队列构成信号，不应解释为年龄/性别足以诊断痛风。
2. C2 对 SPA 的灵敏度达到 0.9149，反映 HLA-B27 等检查套餐对病种的强提示；这种信息可能在不同机构迅速变化。
3. C4 的额外增益主要证明“数值+谁被检查”比数值更容易拟合当前内部标签，不能视为更纯粹的医学性能。
4. C3 的化验值本身参与真实医生诊断流程，因此结论应称为临床辅助主要诊断，而不是独立影像诊断。
5. 当前只做同源内部五折；在获得带隐藏标签的时间外临床表之前，不能声称跨时间或跨中心泛化。

## 决策与下一步

1. 冻结 C3 为异常五分类的临床单模态参考输入；不使用病程和显式缺失 mask；
2. C2 固定为工作流偏差审计，C4 固定为敏感性上限；两者都不是主候选；
3. 不启动两层 MLP 或树模型：C3 已通过预设门槛且无明显 Logistic Regression 欠拟合证据，继续加复杂度会扩大同一开发集上的选择；
4. 未来若有合格图像主模型，融合主方案使用 C3 字段，并按既定 F1/F2 比较 `p=0` 与训练期随机化验遮蔽 `p=0.15`；不输入显式 missing mask；
5. 当前 F0～F2 仍因 A2 无合格图像模型而阻塞，不能用 C3 的高分绕过图像门槛；
6. 2026 标签隐藏队列继续隔离，尚未用于本阶段选择。
