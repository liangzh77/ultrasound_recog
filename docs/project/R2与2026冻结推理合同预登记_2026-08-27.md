# R2与2026冻结推理合同预登记

- 日期：2026-08-27
- 状态：开发集路线已按ADR-023闭合；允许在洁净提交上生成一次正式2026预测
- 目的：以最小复杂度形成可审计的2026一次性图像与分层多模态预测

## 总体原则

不再对R0/E1路线搜索checkpoint、融合权重或置信度阈值。R1已在开发集按ADR-021选择R0自动有效视野，医院无需补有效视野矩形；L0/L1又因强标注偏倚和固定融合失败被ADR-023关闭，医院也无需补病灶轮廓。E1/R1绝对六分类性能不足，因此2026输出只作为一次性研究预测，不宣称临床独立诊断。模型与输入哈希在预测清单中逐项记录。

## ROI分支

- 全自动：五个R0正式检测器各取最高置信框，对可用框做坐标逐项中位数；若五个模型均无检测，使用完整图像兜底并标记；
- 半自动：医院按原图像素提供每张图的有效视野矩形，必须完整覆盖1,819图、唯一连接且坐标合法；
- R0几何指标仍只作描述，最终路线依据R1患者级分类影响和病例审查。

## 图像单模态

五个E1冻结checkpoint分别对同一ROI输入推理。每个模型先在患者内平均逐图六分类概率，再对五个患者概率向量等权平均。不重训E1，不用2026选择某一折或某个checkpoint。

## 分层多模态

C3沿用性别、年龄和六项化验白名单，病程、编号、日期、路径、文件名和显式缺失指示器禁止入模。五个C3模型的异常条件五分类概率等权平均，然后按冻结公式组合：

```text
P(正常) = P_E1集成(正常)
P(异常疾病 d) = (1 - P_E1集成(正常)) × P_C3集成(d | 异常)
```

开发队列正常组没有同标准临床表，因此C3内部证据仍限于767名异常患者，不能把既有C3分数解释为完整六分类性能。2026的225名患者均有同结构临床行，预测后由甲方六分类真值一次性评价完整分层结果；这一限制必须在最终报告中保留。

## 输出与置信度

每名患者同时输出图像单模态和分层多模态的Top-1、Top-2、六类概率、ROI来源及低置信度标记。低置信度仅作复核队列提示，不改变分类：Top-1概率低于0.50，或Top-1与Top-2概率差低于0.10，即标记为需要重点复核。

## 冻结与停止

1. R1已完成，路线冻结为R0自动有效视野；
2. R1结果文档和ADR-021提交后，只允许填入所选分支及R0 checkpoint哈希，不改变聚合规则；
3. 正式预测前验证225人、1,819图、225行临床表和全部权重哈希；
4. 预测包冻结后才交给甲方，甲方返回结构化六分类真值；
5. 不用2026结果切换ROI、改权重、改阈值或选择模型；任何后续调整只能标记为补充工程分析。

机器合同见`configs/research/r2_2026_frozen_inference.yaml`。
