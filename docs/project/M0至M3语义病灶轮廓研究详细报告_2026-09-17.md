# 膝关节超声 M0 至 M3 语义病灶轮廓研究详细报告

医院沟通版  研究方法  完整结果与分析

报告编制日期：2026年9月17日｜实验完成日期：2026年8月28日｜研究范围：患者级主要诊断六分类

## 摘要

本轮研究回答三个递进问题：医生按类别标注的病灶轮廓能否改善患者级超声六分类；完整图像与轮廓像素是否比病灶类别、数量和面积更有价值；进一步加入临床数值能否超过更简单的图像加临床分层方案。研究采用967名患者、4543张图像的既有开发队列，固定患者级五折，比较M0纯图像、M1人工结构化征象、M2图像加13类语义轮廓、M3固定临床融合，并加入M0＋C3分层对照。2026时间外队列不参与本轮训练、选择或评价。[1–7]

M1的macro F1为0.6351，准确率为0.6991；M2的macro F1为0.3327，比M0提高0.1172，但比M1低0.3024。M3加入临床后达到0.5676，比M2提高0.2348，仍低于M0＋C3的0.6018，差值为−0.0342，配对95%区间为−0.0578至−0.0096。当前结果支持人工结构化征象在本批资料中具有疾病区分能力，也支持语义通道相对纯图像的改善；没有建立完整轮廓像素模型优于结构化征象的证据，也不支持替换既有分层方案。

解释中最重要的两个限制是：既往轮廓资料同时反映影像征象与当时的检查、记录方式；临床C3只覆盖767名异常患者，200名正常患者无C3，因此本批资料中临床信息的完整程度与疾病分组存在关联。M1不是自动图像识别结果，M3及M0＋C3尚不能直接代表未来实际就诊人群的六分类表现。

### 核心术语

本报告中的“患者级六分类”是根据同一患者的多张超声图及相应资料，给出正常、类风湿性关节炎、痛风性关节炎、脊柱关节炎、骨性关节炎、损伤中的一个主要诊断类别。“有效视野”指用于分析的完整超声成像区域；“语义轮廓”指带有明确病灶类别的人工轮廓；“临床分层对照”指图像负责提供正常概率、临床数值负责区分异常疾病的组合方法。它们均属于本阶段的研究方法。

宏平均F1（macro F1）兼顾每类的漏判与误判，并对六类同等加权，越高越好；它与“多少患者分对了”的准确率不同。“五折验证”将患者分为五组，轮流用其中一组测试，其余患者用于模型开发；“OOF预测”是每名患者作为测试对象时得到的预测，可用于汇总整批患者的表现。

## 1 研究问题与实验边界

本研究使用既往临床影像及标注资料开展回顾性方法比较。既往资料首先服务于当时的诊疗和记录，其采集目的与本次统一研究评价有所不同；以下局限反映两种用途的差异，不是对临床诊疗或标注质量的评价。目标是每名患者输出一个主要诊断类别，而不是对每张图分别下诊断，也不是预测每一个病灶的分割质量。M2使用的病灶类别和轮廓由医生已有标注提供，因此本轮没有评价自动病灶检出或自动分割器，也没有Dice、IoU或病灶定位准确率作为本轮终点。

| 比较 | 要回答的问题 |
| --- | --- |
| M1与M0 | 人工给定病灶类别、数量、面积具有多大可分性 |
| M2与M0 | 语义轮廓通道加入完整有效视野后有无整体收益 |
| M2与M1 | 所测试的像素模型是否超过结构化征象模型 |
| M3与M2 | 固定临床融合是否改善语义图像流程 |
| M3与M0＋C3 | 较复杂的语义轮廓流程是否值得替代简单分层对照 |

预登记不设置可事后调整的单一通过线，而是综合效应量、置信区间、五折方向、逐类表现、校准与标注工作量。M2五折启动后不按单折结果修改方法；M3只执行一次0.75与0.25的固定融合，不搜索权重。M0复用既有E1严格OOF，因为队列、折分、ROI、分辨率、骨干、训练参数及患者聚合方式与本轮定义一致。[1]

## 3 模型与训练方法

### 3.1 M0 纯图像参照

M0为E1 EfficientNet B2图像模型的既有OOF。每张完整有效视野RGB经384像素letterbox后进入ImageNet预训练骨干，经全局平均池化、dropout和线性六分类头得到逐图softmax概率。患者概率为该患者全部有效图像概率的等权平均；它不是对类别标签投票，也不是先平均特征再分类。最终预测取患者六类概率中的最大值。[1,8]

患者i有n张图时，Pᵢ(c) = (1/n) × Σⱼ softmax(zᵢⱼ)₍c₎。训练损失为患者真实类别平均概率的负对数，即 −log Pᵢ(yᵢ)。图像模型使用患者类别反频率的有放回平衡抽样，避免图像较多的患者被当作更多独立病例。

### 3.2 M1 人工结构化征象模型

每名患者对13类征象分别计算三项输入，共39维。presence表示任一图是否有该类有效轮廓；object count为全部图中的该类有效多边形总数；area fraction为该类逐图并集阳性像素数之和除以患者图像数×384×384。分母包含letterbox画布，因而是画布面积占比，不是物理病灶面积或解剖组织面积。对象数没有作对数变换。[1,3]

M1只使用这些征象，不读取RGB、临床Excel、日期、文件名或身份信息。每个外层训练折拟合StandardScaler，再拟合多项逻辑回归：C=1.0、class weight=balanced、lbfgs、最大2000次迭代；无超参数搜索。预处理与模型拟合均不使用该折外层测试患者。M1不同于图像模型的内层验证早停流程，它是固定参数的外层训练折直接拟合。

### 3.3 M2 图像与语义轮廓联合模型

M2沿用M0的骨干和患者概率平均结构，输入改为3个RGB通道与13个独立语义mask，共16通道。ImageNet预训练通过timm的in_chans参数适配输入层；16通道网络在预训练基础上适配输入层；其中的轮廓来自人工标注。每个正式fold从同一预训练权重独立初始化，不复用pilot checkpoint。[4,5,8]

| 训练项目 | 冻结设置 |
| --- | --- |
| 骨干与输出 | efficientnet_b2.ra_in1k，六分类，dropout 0.30 |
| 画布与患者采样 | 384×384；每训练epoch每患者最多随机取6图 |
| 验证和测试 | 读取患者全部图像；最佳验证epoch冻结后评价外层测试 |

| 正则与稳定性 | weight decay 0.0001；梯度裁剪1.0；AMP开启 |

训练增强对RGB和全部mask同步水平翻转（概率0.5）、−7至＋7度旋转、横纵不超过画布3%的平移、0.95至1.05倍缩放；RGB采用双线性插值，mask采用最近邻插值。亮度与对比度倍率0.85至1.15只作用于RGB。RGB用ImageNet均值和标准差归一化，mask保留独立的二值语义。

### 3.4 C3临床模型及输入边界

C3是已经冻结的异常五分类临床基线，输入为性别、年龄、ESR、CRP、抗CCP、RF、HLA B27和尿酸八项字段。性别按男1女0，HLA B27按阳性1阴性0、缺失中性值0.5；其余所需中位数插补与标准化仅在外层训练折拟合。C3使用固定的平衡多项逻辑回归，不加入显式缺失指示器。身份、诊断文字、病程、日期、文件名和源路径不进入模型。[9]

“Excel是否存在”虽然不作为C3的输入特征，却决定分层流程走哪条分支。因此不显式加入缺失特征，并不能消除整个融合流程中的临床资料覆盖差异带来的偏差。

### 3.5 M3与分层对照的数学定义

令p(c)为M2六分类概率，c=0表示正常；q(c)为M2在异常五类中的条件概率，即p(c)/Σₖ₌₁⁵p(k)；r(c)为C3五分类概率。对于有C3的患者，M3按下列公式计算：[6,8]

P_M3(0) = p(0)
P_M3(c) = [1−p(0)] × [0.75 r(c)＋0.25 q(c)]，c为异常类别。

无C3时直接保留M2原始六分类概率。M0＋C3对照采用M0的正常概率，对有C3者将剩余概率质量完全按C3五类分配；无C3时保留M0六分类。两者都不是“正常概率大于0.5就判正常”的硬阈值门控，最终仍对完整六类概率取argmax。

M3没有新增模型训练，也没有学习融合权重。其与M0＋C3的差别同时包括正常概率来源（M2或M0）以及异常条件概率是否混入25%图像分量，故完整六分类差异不能只归因于某一个因素。767人异常条件分析可单独观察混合概率的表现，但未构成独立的正常门控因果消融。

## 4 统计评价方法

主要终点是合并967名患者OOF后的六类macro F1，即每类F1的等权平均。OOF指每人的预测来自没有用该人进行拟合的对应外层模型。总体OOF macro F1不是五个fold macro F1的算术平均，因为F1对混淆矩阵是非线性的。准确率按患者比例计算；平衡准确率为各类灵敏度平均；Top 2为真值进入最高两个概率类别的比例。[8]

逐类灵敏度为TP/(TP+FN)，特异度为TN/(TN+FP)，精确率为TP/(TP+FP)，NPV为TN/(TN+FN)，F1为精确率和灵敏度的调和平均。各类AUC按一类对其余类计算，macro AUC为其平均值；AUC反映排序，不表示argmax分类在当前阈值下同样好。分母为零的精确率等指标记为未定义，F1按代码zero_division=0处理。

ECE将最高类别置信度划分为10个等宽区间，按各区间样本占比加权置信度与实际正确率的绝对差；Brier为六类预测概率与one hot真值平方差之和，再按患者取平均。两者越低越好，但低ECE单独不能证明识别能力强；弱模型也可能以低置信度获得较低ECE。五类与六类Brier的任务结构不同，应在相同任务内解释。

95%区间使用2000次按参考诊断分层的患者bootstrap，随机种子20260724，每类有放回抽取原类人数。配对差值对两模型使用相同抽样患者，取差值分布2.5%和97.5%分位数。该区间基于已固定OOF预测，不在每次bootstrap中重新训练，不能覆盖全部训练随机性、中心差异或未来人群偏移。正向bootstrap比例是重采样差值大于零的频率，不等于贝叶斯模型胜出概率，也不应直接当作传统p值。五组比较未进行多重比较校正，区间应作为预登记探索性证据解释。

## 9 结果的临床研究意义

### 9.1 语义标签信息与像素信息需要分开解释

M1没有看RGB，却达到本轮最高macro F1，说明医生已经给出的病灶类别及其分布是强信号。既有S1只用13类是否出现的macro F1为0.6087，M1加入对象数和面积后为0.6351，名义差约0.0264；这是既有结果的背景对照，不是本轮新增的同一配对消融，不能把全部差值确定归因于数量和面积。[3]

M2同时获得类别、轮廓与图像，其超过M0只能证明整体输入方案有增量，不能独立证明“形状”或“空间关系”有贡献。要分解来源，需要事先设计的去类别、打乱空间、仅mask、仅结构化征象等针对性消融；这些分析不在本轮实验范围内，需要后续另行设计验证。

### 9.2 融合并不天然产生互补收益

M3相对M2的大幅提升表明临床分支为该流程提供了有效信息，但较强模型与较弱模型的平均不必优于强模型。异常条件分析显示M2明显弱于C3，固定混合后分类和校准没有稳定获益；完整六分类同时受到M2正常分支表现限制。本轮结果不足以支持继续在同一开发集搜索融合比例。

### 9.3 研究结论及适用范围

本轮证据支持以下结论：当前历史队列中，人工结构化征象在本批资料中具有较强的疾病区分能力；所测试的语义通道网络优于其纯图像参照；所测试的完整图像与轮廓模型没有超过结构化征象；固定临床融合没有超过简单分层对照。这些结论对应明确的模型、数据版本和评价方式。

这些结果尚不能外推为自动病灶识别能力或前瞻性临床诊断性能；当前轮廓模型的不足，也不代表轮廓信息在其他方法中没有研究价值。M1的表现为后续标准化征象研究提供了依据，其实际辅助诊断价值仍需独立资料验证。

## 10 局限与后续验证条件

第一，历史标注不是逐图穷尽的阴阳性记录。不存在轮廓可能对应真阴性、未观察、未记录或切面不可见，类别支持与诊断集中也明显不均。患者级分折能防止同一患者资料同时进入训练与测试，却不能消除跨患者稳定存在的与疾病分组相关的既往记录差异。

第二，临床覆盖与诊断关联。所有正常患者缺C3，所有异常患者有C3，导致流程中不同参考类别走不同分支。当前融合结果仅适合历史工作流敏感性分析；后续宜在真实目标人群中统一采集临床字段并预先约定缺失处理，才能评价部署流程。

第三，967名患者并不意味着每种征象都有足够独立病例，单患者支持的稀有类不能提供稳定的跨折阳性学习。图像数、对象数和像素数都不能代替独立患者数。M1对象数及面积还可能受每人采集图数、切面和重复记录影响。

第四，当前研究只比较冻结的学习器与参数，没有在独立资料上评价不同标注者之间的一致性、标注耗时、真实严重程度或跨中心变化。bootstrap只刻画固定OOF在当前队列上的患者抽样不确定性。既往在相同开发队列上的多轮研究还会带来研究者适应性选择风险；本轮预登记降低了本轮自由度，但不能把历史开发队列变成外部验证集。

后续建议优先开展标准化的独立资料采集与标注：逐图记录存在、不存在、不可见、不确定；每个轮廓绑定冻结类别；记录标注者及版本，尽量对最终诊断和AI结果盲法；先检查一致性和支持度，再固定模型和统计计划。M1应作为正式对照持续保留，M2需要在这种数据上重新证明增量。另需记录医生标注时间，评价复杂轮廓流程的实际成本，而不只比较分数。

本轮尚未获得支持变更既有研究预测方案的证据。后续工作的重点宜由继续调整同一批资料上的模型，转向标准化资料补充与独立验证；2026队列可按既定方案，在获得医院参考诊断后开展独立评价。该队列没有进入本报告的M0至M3性能比较，不能把开发结果与时间外验证混写。[7]
