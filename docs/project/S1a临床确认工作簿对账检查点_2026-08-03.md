# S1a临床确认工作簿对账检查点

## 结论

临床确认严格门已补齐只读Excel/YAML逐项对账。验证器不再只检查完成工作簿的容器、页名和哈希，而会核对八项医学决定、八项复核参数、逐行角色/日期及双签署。任一差异均失败关闭，且错误只列安全字段编号。

真实临床回传表尚未收到，因此本检查点只证明对账合同和失败路径可执行，不声称临床定义已经确认，也不启动正式复核、病变监督训练或模型选择。

## 研究问题和预设门槛

研究问题：能否在不引入Excel运行时依赖、不保存姓名和不自动改写配置的前提下，机器证明医生回表与研究确认YAML逐项一致？

预设门槛：

- 仅只读解析`填写说明`、`医学定义确认`和`复核参数确认`三个固定工作表及规定单元格；
- 支持共享字符串、内联字符串、数字、布尔值、ISO日期和Excel日期序号；
- Q1～Q8状态、选项、操作性定义、理由、逐行角色存在性和日期全部一致；
- P1～P8状态、类型化最终值和理由全部一致；
- 临床/研究双签署存在且最终日期一致；
- 姓名不得出现在返回值或错误；XML读取有单文件和总量上限；
- 不一致、缺失或不可解析时必须抛错，不生成冻结建议；
- 验证器不得修改工作簿、确认YAML或复核配置。
