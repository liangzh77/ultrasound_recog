# 区域/病变标注监督审计结果

## 阶段结论

S1审计完成。规范化数据合同通过：967名开发患者的4,543张纳入图像均可连接到28类版本化标注，未知类别和疾病前缀残留均为0。但现有标注不能直接作为“28类互斥语义分割 + 人工病变特征诊断”的训练合同：9类患者级支持不足、4,346对跨类别多边形存在正面积重叠、逐图未标类别不具备真阴性含义，而且仅凭人工标注类别的出现情况就能高度区分主要诊断。

因此本阶段不启动平铺28类nnU-Net、不把人工标签存在性输入患者诊断，也不把0.8240解释成图像识别性能。下一步先冻结临床审阅的分层本体、逐图穷尽性/阴性协议和重叠表达，再预登记一个窄范围辅助任务。

## 数据合同和覆盖

- 4,543/4,543张纳入图像有标注JSON，连接覆盖率100%；无孤立的纳入标注记录；
- 共10,989个对象，其中10,988个多边形可用，1个无法修复；
- 1,060个原始无效多边形经确定性几何修复后可用；
- 5张图有JSON但对象数为0，含对象图像覆盖率99.89%；
- 546个对象没有完全落在人工确认ROI内；未来若只读ROI，转换器必须显式裁切并登记截断，不能静默丢弃或读取ROI外像素；
- 48个对象记录面积与重算多边形面积相差超过5%；训练应以修复后多边形重算面积，不能信任旧面积字段；
- 28类合同、未知类别0、疾病前缀残留0，数据与泄漏硬门槛通过。

这些统计只覆盖已排除“滑膜囊肿”主要诊断后的六类开发队列，因此对象总数与全量规范化报告不同是预期结果。

## 类别支持度

| 支持等级 | 类别数 | 类别 |
|---|---:|---|
| robust，多折充分 | 16 | 内侧副韧带、内侧半月板、滑膜、滑膜血流、痛风石、积液、结晶、股四头肌腱、腘窝囊肿、软骨、骨侵蚀、骨皮质、骨赘、髂胫束、髌前浅筋膜、髌韧带 |
| limited，多折有限 | 3 | 外侧副韧带、股二头肌腱、鹅足腱 |
| insufficient，多折不足 | 9 | 半月板囊肿、半膜肌、半膜肌腱、囊肿、滑膜囊肿、髌下深囊炎、髌前血肿、鹅足腱滑囊、鹅足腱滑囊炎 |

工程角色暂分为13类解剖、13类病变、2类含义待确认；角色划分不是临床最终本体。9个不足类不能单独进入正式五折目标，3个有限类只适合作探索或上层合并。痛风石和结晶虽然支持度达到多折门槛，但均只出现在痛风主要诊断患者中，必须按高诊断集中风险处理。

共13类的单一诊断患者占比≥0.80，其中10类≥0.95。这可能同时反映真实病理特异性、切面选择、已知诊断影响标注以及未穷尽标注，不能只凭内部数据区分。

## 多边形重叠与任务表达

- 检出4,377对正面积重叠对象，其中4,346对为跨类别，31对为同类别；
- 最大重叠关系为“滑膜—滑膜血流”2,091对/370图，其次为“软骨—骨皮质”813对/770图、“滑膜—积液”392对/306图；
- `single_multiclass_mask_safe=false`。

这些重叠具有合理医学含义，例如血流位于滑膜区域、软骨与骨皮质边界相邻或重叠。把所有对象按绘制顺序覆盖到一张互斥类别mask会人为删除监督并让结果依赖标注顺序。后续若训练，应使用保留实例的多标签表示、分层任务头或临床确认后的非冲突子集。

## 人工标注存在性偏差代理

输入不是像素，而是每名患者28类人工标注是否出现。每个组都严格使用固定外层五折，OOF覆盖967名唯一患者；模型为类别平衡多项Logistic Regression。95% CI采用2,000次患者分层bootstrap，seed 20260724。

| 特征组 | 特征数 | OOF macro-F1（95% CI） | OOF macro-AUC（95% CI） | fold macro-F1 |
|---|---:|---:|---:|---|
| 全部人工类别 | 28 | 0.8240（0.8010～0.8466） | 0.9668（0.9602～0.9730） | 0.8006 / 0.8604 / 0.8552 / 0.8033 / 0.8021 |
| 仅解剖角色 | 13 | 0.5407（0.5117～0.5696） | 0.8404（0.8260～0.8551） | 0.5451 / 0.5620 / 0.5496 / 0.5144 / 0.5287 |
| 仅病变角色 | 13 | 0.6087（0.5815～0.6334） | 0.8965（0.8845～0.9081） | 0.4881 / 0.6113 / 0.6732 / 0.5247 / 0.5944 |

三组均远超预登记的macro-F1 0.20或macro-AUC 0.65高可分门槛。尤其“仅解剖角色”也高度可分，说明不只是痛风石等特异病变，切面/结构选择和标注工作流也携带诊断信息。

这不是模型已经从超声像素诊断正确。它证明的是：医生选择拍什么、标什么以及如何命名，与已知主要诊断强相关。人工标注存在性若直接作为诊断输入，会把参考标准形成过程带入模型；即使后续训练病变预测器，也必须在患者级外层折内训练并只生成OOF病变特征，且仍需把标注流程偏差列为局限。

## 局限性

- 诊断集中不能区分真实病理特异性和标注者已知诊断造成的选择偏差；
- 当前没有双人复标或标注者信息，不能估计观察者间一致性；
- 多边形修复和ROI越界只完成结构审计，尚未形成训练转换规则；
- 人工存在性代理评价的是标注工作流，不是图像诊断、病变检测或分割能力；
- 数据来自单一现有开发来源，不支持部署声明。
