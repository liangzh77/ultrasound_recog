# 区域/病变标注监督审计预登记

## 状态

审计实现、配置和合成测试已经完成；尚未在真实标注上运行。本文在查看覆盖率、重叠、类别支持度或人工标注存在性代理结果前，冻结研究问题、门槛和解释边界。

## 研究问题

现有疾病前缀已移除的 28 类多边形标注，能否安全地用于下一阶段的病变定位、分割或患者诊断辅助监督？具体检验：

1. 规范化类别合同和图像—标注连接是否完整、几何是否可用；
2. 各类是否具有足够的患者级、五折级支持；
3. 跨类别多边形是否重叠，因而不能直接压成一张互斥多类语义 mask；
4. 标注类别是否过度集中于某一种主要诊断；
5. 仅凭“医生标了哪些类别”能否预测疾病，从而暴露标注流程、病变定义或疾病标签之间的捷径。

## 预设假设与门槛

### 数据与泄漏硬门槛

- `category_mapping.json` 必须恰好包含 28 类；
- 规范化标注中未知类别对象必须为 0；
- 带疾病前缀的残留对象必须为 0；
- 报告、OOF 和 MLflow 只允许聚合统计以及伪匿名 `person_key`/`image_key`，不得写姓名、原文件名、私有连接字段或原始路径；
- 2026 标签隐藏队列不读取、不预测、不参与门槛。

任一硬门槛失败即停止后续分割/多任务设计，先修复数据版本。

### 类别支持度

按患者而不是对象数判定：

- `robust_multifold`：至少 50 名患者，且每个外层 fold 至少 5 名患者；
- `limited_multifold`：至少 20 名患者，且每个外层 fold 至少 2 名患者；
- 其他为 `insufficient_multifold`，不得单独作为正式 5-fold 目标。

支持度不足不是删除阴性结果的理由；可以在临床确认后合并为更高层本体、只作描述，或等待新增数据。

### 诊断集中和标注捷径

- 某类别患者中单一诊断占比达到 0.80/0.95 时分别标记高/极高诊断集中；这不是自动泄漏定罪，而是需要临床解释和独立泛化验证的风险信号；
- 用患者人工标注类别“是否出现”的二元向量做固定外层五折、类别平衡多项 Logistic Regression；分别审计全部类别、解剖类、病变类；
- 若任一组 OOF macro-F1 ≥ 0.20 或 macro-AUC ≥ 0.65，则判为高可分性，提示人工标注选择本身携带强疾病/工作流信息；该代理只做偏差审计，绝不作为可部署图像性能。

### 几何与任务表达

- 跨类别多边形存在正面积重叠时，禁止把全部 28 类直接压为单张互斥多类 mask；
- `anatomy`、`finding`、`ambiguous` 角色为工程预分类，必须经过临床方确认；
- 当前没有“逐图穷尽性阴性标注”协议，因此未出现某类别不能自动解释为真正阴性；
- 人工标注存在性不得直接输入患者诊断模型。未来病变特征只能来自严格患者级外层折内训练后生成的 OOF 预测。

## 预设决策规则

- 数据硬门槛失败：S1 保持阻塞，修复标注版本后重新预登记；
- 存在跨类别重叠：优先保留实例/多标签表达，不启动平铺 28 类 nnU-Net 语义 mask；
- 多数类别支持不足：不启动 28 类平铺正式五折，转向临床定义的高支持病变集合或分层本体；
- 人工存在性代理高可分：将其记录为偏差/捷径，不把人工标签或由全数据训练得到的病变预测用于诊断评估；
- 只有在目标语义、阴性含义、类别本体、支持度和OOF生成方法都通过后，才另写ADR和新预登记选择 YOLO-seg、nnU-Net 或多任务模型；本审计本身不选择模型。

所有阳性、阴性、失败和停止结果都写入研究台账；不得仅保留有利发现。
